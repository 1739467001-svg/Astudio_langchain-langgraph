## 一、核心概念：什么是 LLM

### 1.1 大语言模型（LLM）是什么

你可以把 LLM 想象成一个**读过互联网上几乎所有文字的超能实习生**。你给它一段文字（Prompt），它就根据自己"读过的东西"预测接下来最可能的内容。

几个关键特征：

- **输入文字、输出文字**：LLM 的输入叫 Prompt（提示词），输出叫 Response（响应）
- **基于概率**：它不是"查找答案"，而是"预测最可能的下一个词"
- **无状态**：每次调用都是独立的，LLM 本身不记得你上一次说了什么（这个限制很重要，后面的 Memory 课就是为了解决它）
- **上下文窗口有限**：LLM 一次能处理的文字长度有上限，不同模型从 4K 到 200K+ tokens 不等

### 1.2 什么是 Token

Token 是 LLM 处理文字的基本单位。它不等于一个字或一个词：

- 英文中：`"Hello world"` 大约是 2 个 token
- 中文中：一个汉字通常是 1-2 个 token
- 计费、上下文长度限制都以 token 为单位

> 💡 简单理解：大约 1 个英文单词 ≈ 1 token，1 个中文字 ≈ 1.5 token

### 1.3 什么是 API 调用

你不需要在本地运行一个几百 GB 的大模型。大多数情况下，你通过 **API（应用程序接口）** 调用云端部署的模型：

```
你的代码  →  发送请求（Prompt + 参数）  →  云端 LLM  →  返回响应  →  你的代码
```

就像打电话：你拨号码（API 请求），对方接听处理，然后回复你（API 响应）。

### 1.4 常见 LLM 服务商

| 服务商 | 模型 | 特点 |
|--------|------|------|
| OpenAI | GPT-4o, GPT-4o-mini | 最流行，文档丰富，适合学习 |
| Anthropic | Claude 3.5 | 长文本处理能力强 |
| 科大讯飞 | 星火大模型 | 国内可用，中文友好 |
| 阿里云 | 通义千问 | 国内可用，开源生态好 |
| Google | Gemini | 多模态能力强 |
| 本地部署 | Ollama + 开源模型 | 免费，隐私好，但需要较好的硬件 |

> 📌 **学习建议**：初学者推荐使用 OpenAI 的 API（GPT-4o-mini 便宜且好用）。如果你在国内不方便访问 OpenAI，可以使用科大讯飞星火或阿里云通义千问。

## 二、环境搭建

### 2.1 安装 Python

1. 前往 [python.org](https://www.python.org/downloads/) 下载 Python 3.9 或更高版本
2. 安装时勾选 "Add Python to PATH"（Windows）
3. 验证安装：
   ```bash
   python --version
   # 应该输出类似 Python 3.11.x
   ```

> 📌 详细的多平台安装步骤见 [知识库：环境配置指南](../知识库/06-环境配置指南.md)

### 2.2 创建虚拟环境

虚拟环境可以隔离每个项目的依赖包，避免版本冲突：

```bash
# 在你的项目目录下执行
python -m venv venv

# 激活虚拟环境
# macOS / Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# 激活后命令行前面会出现 (venv) 标志
```

### 2.3 安装 LangChain

```bash
# 安装 LangChain 核心包和社区集成包
pip install langchain langchain-openai langchain-community

# 安装 LangGraph
pip install langgraph

# 可选：安装其他常用工具
pip install python-dotenv jupyter
```

### 2.4 配置 API Key

1. 注册 OpenAI 账号并获取 API Key：[platform.openai.com](https://platform.openai.com/api-keys)
2. 在项目根目录创建 `.env` 文件：
   ```env
   OPENAI_API_KEY=sk-你的密钥放这里
   ```
3. **重要**：确保 `.gitignore` 中包含 `.env`，不要把密钥提交到代码仓库

### 2.5 验证一切就绪

创建一个 `test_setup.py` 文件：

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

# 加载环境变量
load_dotenv()

# 创建 LLM 实例
llm = ChatOpenAI(model="gpt-4o-mini")

# 测试调用
response = llm.invoke("你好，请用一句话介绍你自己。")
print(response.content)
```

运行它：

```bash
python test_setup.py
```

如果看到模型回复了一段中文，恭喜你——环境搭建成功！

## 三、零基础需要知道的 Python 概念

以下概念在后续课程中会频繁出现，如果你还不熟悉，建议先花时间了解：

| 概念 | 一句话解释 | 在 LangChain 中的用途 |
|------|-----------|----------------------|
| 变量与字符串 | 存储和操作文本 | 处理 Prompt |
| 字典 dict | 键值对数据结构 | 消息格式、配置 |
| 列表 list | 有序集合 | 存储对话历史 |
| 函数 def | 可复用的代码块 | 自定义工具和逻辑 |
| 类 class | 面向对象编程 | 理解组件结构 |
| import | 导入模块 | 引入 LangChain 各模块 |
| 异步 async/await | 非阻塞操作 | 流式输出、并发调用 |
| 装饰器 @ | 函数增强 | 部分扩展场景 |

> 💡 如果上面有些概念不熟悉也没关系——我们会在用到时再解释。你也可以配合任何 Python 入门教程同步学习。
