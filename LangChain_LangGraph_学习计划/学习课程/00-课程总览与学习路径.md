## 一、这门课程解决什么问题

你大概已经听说过 ChatGPT、大语言模型（LLM）这些词。LangChain 和 LangGraph 就是帮助开发者**用 LLM 构建实际应用**的两个框架：

- **LangChain**：让 LLM 能够连接外部数据、调用工具、记住上下文、执行复杂逻辑——把一个"只会聊天的模型"变成"能干活的助手"。
- **LangGraph**：当你的应用需要多个步骤、多个 Agent 协作、需要条件分支和循环时，LangGraph 提供了图式编排能力——就像画流程图一样编排 AI 工作流。

学完本课程，你将能够：

1. 理解 LLM 应用开发的完整图景
2. 使用 LangChain 构建带记忆、工具调用、RAG 的智能应用
3. 使用 LangGraph 构建多步骤、多 Agent 的复杂工作流
4. 独立完成一个端到端的 AI 应用项目

## 四、学习节奏建议

### 4.1 每课的学习流程

每节课按照以下结构组织，建议你也按这个顺序学习：

1. **阅读学习目标**：明确这节课学完应该会什么
2. **概念讲解**：理解原理（遇到不懂的词去知识库查）
3. **代码示例**：跟着敲一遍，确保能跑通
4. **动手练习**：独立完成小练习，巩固理解
5. **知识库链接**：深入了解更多技术细节
6. **自测清单**：检查是否真正掌握

### 4.2 时间规划

- **每天 1-2 小时**，大约 6-8 周可以完整学完
- **每周 3-5 天**学习新内容，其余时间复习和练习
- **不要跳课**：每节课都建立在前一课的基础上

### 4.3 学习心态

- 不需要一开始就理解所有细节，先跑通再说
- 报错是正常的，知识库的排错指南就是为这时准备的
- 善用知识库：它是你的速查手册，不需要背下来
