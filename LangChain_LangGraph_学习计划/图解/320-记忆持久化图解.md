# Agent 记忆持久化图解

> 三层记忆架构：短期(Checkpointer) + 长期(Store) + 情景(向量库)，实现跨会话记忆。

---

```mermaid
graph TB
    USER["用户输入"] --> SHORT["短期记忆<br/>Checkpointer"]
    SHORT --> AGENT["Agent 执行"]

    AGENT -->|"会话结束<br/>固化"| LONG["长期记忆<br/>BaseStore"]
    AGENT -->|"关键事件<br/>编码"| EPISODIC["情景记忆<br/>向量库"]

    LONG -->|"按 user_id 检索"| AGENT
    EPISODIC -->|"语义相似检索"| AGENT

    subgraph 三层 {"记忆层次"}
        SHORT
        LONG
        EPISODIC
    end

    style SHORT fill:#E3F2FD,stroke:#1565C0
    style LONG fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style EPISODIC fill:#F3E5F5,stroke:#6A1B9A
```

---

## 三层记忆对比

| 层次 | 存储 | 生命周期 | 检索方式 | 典型用途 |
|------|------|----------|----------|----------|
| 短期 | Checkpointer (内存/Redis) | 单次会话 | thread_id | 对话上下文 |
| 长期 | BaseStore (Postgres/KV) | 跨会话 | key 前缀查询 | 用户偏好/事实 |
| 情景 | 向量库 (FAISS/PGVector) | 永久 | 语义相似度 | 历史经验/案例 |
