# 知识沉淀图解

> 用图解理解组织记忆的三层模型和知识沉淀流程。

---

## 一、组织记忆三层

```mermaid
graph TB
    subgraph 三层 {"组织记忆三层模型"}
        L1["Layer 1: 知识缓存<br/>问答对精确匹配<br/>实现: dict/Redis<br/>命中: 0ms ✅最快"]
        L2["Layer 2: 经验库<br/>语义检索历史案例<br/>实现: 向量库<br/>命中: +100ms"]
        L3["Layer 3: 模式总结<br/>LLM从案例提炼规律<br/>实现: 定期批量处理<br/>价值: 抽象知识"]
    end

    L1 --> L2 --> L3

    style L1 fill:'#C8E6C9'
    style L2 fill:'#E3F2FD'
    style L3 fill:'#F3E5F5'
```

## 二、知识沉淀流程

```mermaid
graph LR
    subgraph 沉淀 {"知识沉淀流程"}
        Q["用户问题"] --> C1{"查缓存?"}
        C1 -->|"命中"| R1["返回缓存答案 ✅"]
        C1 -->|"未命中"| C2{"查经验库?"}
        C2 -->|"有相关"| OPT["基于经验优化Prompt"]
        C2 -->|"无"| DIRECT["直接处理"]
        OPT --> GEN["LLM生成回答"]
        DIRECT --> GEN
        GEN --> STORE["沉淀: 存缓存+存经验"]
        STORE --> OUT["返回回答"]
    end

    style C1 fill:'#FFF9C4'
    style STORE fill:'#C8E6C9'
```

## 三、无记忆 vs 有记忆

```mermaid
graph TB
    subgraph 无记忆 {"❌ 无组织记忆"}
        U1["用户A问→处理→回答"] --> N1["知识未保存"]
        N1 --> U2["用户B问同样→重新处理"]
        U2 --> N2["❌ 重复消耗Token+时间"]
    end

    subgraph 有记忆 {"✅ 有组织记忆"}
        A1["用户A问→处理→回答→沉淀"] --> Y1["知识已保存"]
        Y1 --> A2["用户B问同样→命中记忆→快速回答"]
        A2 --> Y2["✅ 省Token+省时间+体验好"]
    end

    style 无记忆 fill:'#FFCDD2'
    style 有记忆 fill:'#C8E6C9'
```
