# 流式输出前端集成图解

> 用图解理解 SSE 流式全链路、React/Vue 集成和体验优化策略。

---

## 一、流式全链路

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as 前端
    participant BE as 后端
    participant LLM as LLM

    U->>FE: 发送消息
    FE->>BE: POST /chat/stream
    BE->>LLM: 流式请求
    loop Token流
        LLM-->>BE: Token chunk
        BE-->>FE: SSE: data{content}
        FE->>U: 打字机效果
    end
    BE-->>FE: SSE: {done:true}
    FE->>U: 渲染完成
```

## 三、后端SSE流程

```mermaid
graph TB
    REQ["POST请求"] --> BUILD["构建消息"]
    BUILD --> STREAM["LLM.astream()"]
    STREAM --> LOOP{"有更多Token？"}
    LOOP -->|是| YIELD["yield SSE data"]
    YIELD --> STREAM
    LOOP -->|否| DONE["yield done"]
    DONE --> RESP["StreamingResponse"]

    style STREAM fill:#FFF9C4
    style YIELD fill:#E3F2FD
```

## 四、前端消费流程

```mermaid
graph TB
    SEND["fetch POST"] --> READ["获取ReadableStream"]
    READ --> DECODE["TextDecoder解码"]
    DECODE --> PARSE["按行解析SSE"]
    PARSE --> TYPE{"事件类型"}
    TYPE -->|token| APPEND["追加到显示内容"]
    TYPE -->|tool_start| TOOL1["显示工具调用"]
    TYPE -->|tool_end| TOOL2["显示工具完成"]
    TYPE -->|done| FINISH["渲染完成"]

    style TYPE fill:#FFF9C4
    style APPEND fill:#E3F2FD
    style FINISH fill:#C8E6C9
```
