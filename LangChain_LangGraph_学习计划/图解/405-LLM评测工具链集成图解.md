## 组合评测流水线

```mermaid
graph TB
    DATA["评测数据集"] --> RUN["运行 RAG/Agent"]
    RUN --> COLLECT["收集输出"]

    COLLECT --> D1["Ragas<br/>RAG 指标"]
    COLLECT --> D2["DeepEval<br/>行为断言"]
    COLLECT --> D3["Promptfoo<br/>Prompt 对比"]
    COLLECT --> D4["LangSmith<br/>追踪+评估"]
```

## Ragas 四大指标

```mermaid
graph TB
    RAGAS["Ragas 核心指标"]

    RAGAS --> F["Faithfulness 忠实度<br/>回答是否基于文档<br/>低分=幻觉"]
    RAGAS --> AR["Answer Relevancy 相关性<br/>回答是否切题<br/>低分=答非所问"]
    RAGAS --> CP["Context Precision 精确率<br/>检索文档是否相关<br/>低分=噪声多"]
    RAGAS --> CR["Context Recall 召回率<br/>是否检索到所有信息<br/>低分=遗漏"]
```

## CI/CD 集成

```mermaid
graph LR
    PR["Pull Request"] --> TEST["自动测试"]
    TEST --> DEEPEVAL_CI["DeepEval 单元测试"]
    TEST --> RAGAS_CI["Ragas RAG 评估"]
    TEST --> PROMPTFOO_CI["Promptfoo 对比"]
    DEEPEVAL_CI --> GATE{"通过率 ≥ 80%?"}
    RAGAS_CI --> GATE
    PROMPTFOO_CI --> GATE
    GATE -->|"通过"| MERGE["✅ 合并部署"]
    GATE -->|"不通过"| REJECT["❌ 阻止合并"]

    style MERGE fill:#C8E6C9,stroke:#2E7D32
    style REJECT fill:#FFCCBC,stroke:#D84315
```

## 指标优化方向

| 指标低分 | 可能原因 | 优化方向 |
|---------|---------|---------|
| 忠实度低 | 幻觉/编造 | Prompt 约束 + 事实校验 |
| 相关性低 | 答非所问 | 查询理解 + 上下文组装 |
| 精确率低 | 检索噪声 | 重排序 + 调 Top-K |
| 召回率低 | 信息遗漏 | 增加分块 + 混合检索 |
