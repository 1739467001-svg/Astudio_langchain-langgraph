# 多跳问答图解

> 复杂问题分解为子问题→串行检索→中间答案作为下一个检索的上下文→合成最终答案。

---

```mermaid
graph TB
    Q["复杂问题"] --> DECOMP["子问题分解"]
    DECOMP --> SQ1["子问题1<br/>营收最高的AI公司?"]
    DECOMP --> SQ2["子问题2<br/>该公司的创始人?"]
    SQ1 --> RET1["检索1"]
    RET1 --> ANS1["中间答案: 公司A"]
    SQ2 --> RET2["检索2<br/>查询含ANS1"]
    RET2 --> ANS2["最终答案"]
    ANS1 & ANS2 --> MERGE["合成"]

    style DECOMP fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style RET2 fill:#E3F2FD,stroke:#1565C0
    style MERGE fill:#C8E6C9
```

---

## 多跳类型

| 类型 | 依赖 | 难度 |
|------|------|------|
| 链式 | 严格串行 | 中 |
| 桥接 | 需合并 | 中高 |
| 比较 | 可并行 | 中 |
| 推理跳跃 | 隐式 | 高 |
