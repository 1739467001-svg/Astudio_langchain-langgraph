# 隐私计算与联邦学习图解

> 数据可用不可见——隐私计算让多方在不泄露原始数据的前提下共同训练或推理。本图解可视化四大技术路线。

## 四大技术路线

```mermaid
graph TB
    PET["隐私计算"]

    PET --> DP["差分隐私<br/>加噪声<br/>快、统计级安全"]

    PET --> MPC["安全多方<br/>秘密分享<br/>中、多方协作"]
```

## 联邦学习原理

```mermaid
graph TB
    subgraph "参与方 A（医院A）"
        DA["本地数据"] --> TA["本地训练"]
        TA --> GA["上传梯度"]
    end
    subgraph "参与方 B（医院B）"
        DB["本地数据"] --> TB["本地训练"]
        TB --> GB["上传梯度"]
    end

    GA --> AGG["中心服务器<br/>聚合梯度"]
    GB --> AGG
    AGG --> UPDATE["更新全局模型"]
    UPDATE --> TA
    UPDATE --> TB

    style DA fill:#C8E6C9,stroke:#2E7D32
    style DB fill:#C8E6C9,stroke:#2E7D32
    style AGG fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
```

## 技术对比

| 技术 | 安全性 | 性能 | 适用 |
|------|--------|------|------|
| 差分隐私 | 统计级 | 快 | 数据发布 |
| 同态加密 | 密码学级 | 慢 | 云端推理 |
| 安全多方 | 密码学级 | 中 | 联合建模 |
| 联邦学习 | 取决协议 | 中 | 跨机构 |
| 可信执行 | 硬件级 | 快 | 云端推理 |
