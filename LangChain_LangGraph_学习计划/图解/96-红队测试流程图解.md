# 红队测试流程图解

> 用图解理解 LLM 攻击面分类、红队测试流程和防御验证闭环。

---

## 一、红队 vs 普通安全测试

```mermaid
graph TB
    subgraph 普通 {"普通安全测试"}
        N1["检查已知漏洞"] --> N2["用规则和扫描器"]
        N2 --> N3["关注代码层面"]
    end

    subgraph 红队 {"LLM红队测试"}
        R1["模拟真实攻击者"] --> R2["用LLM生成攻击"]
        R2 --> R3["关注模型行为"]
        R3 --> R4["发现未知漏洞"]
    end

    style 普通 fill:#E3F2FD
    style 红队 fill:#FFCDD2
```

## 五、自动化执行流程

```mermaid
graph TB
    CASE["攻击用例"] --> SEND["发送攻击载荷给目标LLM"]
    SEND --> RESP["获取LLM响应"]
    RESP --> JUDGE["LLM-as-Judge评估"]
    JUDGE --> RESULT{"攻击成功？"}
    RESULT -->|是| VULN["❌ 发现漏洞<br/>记录严重度"]
    RESULT -->|否| SAFE["✅ 防御成功"]
    VULN --> REPORT["生成报告"]
    SAFE --> REPORT

    style SEND fill:#FFCDD2
    style JUDGE fill:#FFF9C4
    style VULN fill:#FFCDD2
    style SAFE fill:#C8E6C9
```

## 八、防御验证闭环

```mermaid
graph TB
    VULN["发现漏洞"] --> FIX["实施防御"]
    FIX --> RETEST["重新运行攻击套件"]
    RETEST --> CHECK{"攻击仍成功？"}
    CHECK -->|否| PASS["✅ 防御有效"]
    CHECK -->|是| FIX
    PASS --> BASELINE["更新安全基线"]
    BASELINE --> CI["纳入CI/CD回归"]

    style VULN fill:#FFCDD2
    style PASS fill:#C8E6C9
    style CI fill:#E3F2FD
```
