# 幻觉检测图解

> 分句拆分 → 逐句校验 → 置信度评分——让幻觉无所遁形。

---

```mermaid
graph TB
    ANSWER["LLM回答"] --> SPLIT["分句拆分"]
    SPLIT --> CHECK{"事实校验"}
    CHECK -->|上下文支持| OK["可信"]
    CHECK -->|可推断| WEAK["弱支持"]
    CHECK -->|无依据| HALLUC["幻觉"]
    CHECK -->|无法判断| UNK["不可验证"]
    OK & WEAK & HALLUC & UNK --> SCORE["置信度评分"]
    SCORE --> FLAG{"低于阈值?"}
    FLAG -->|是| REVIEW["标记需人工复核"]
    FLAG -->|否| PASS["通过"]

    style CHECK fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style HALLUC fill:#FFCDD2,stroke:#C62828
    style OK fill:#C8E6C9
    style REVIEW fill:#FFE0B2,stroke:#E65100
```

---

## 幻觉类型

| 类型 | 定义 | 检测难度 |
|------|------|----------|
| 上下文矛盾 | 与文档矛盾 | 中 |
| 上下文虚构 | 编造不存在信息 | 高 |
| 逻辑跳跃 | 推理链断裂 | 高 |
