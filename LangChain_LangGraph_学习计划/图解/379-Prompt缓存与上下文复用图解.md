## 缓存友好的 Prompt 结构

```
✅ 友好：[稳定系统提示] → [稳定知识库] → [Few-Shot] → [增长历史] → [新问题]
                                全部可缓存                    新增部分

❌ 不友好：[时间戳] → [系统提示] → [问题]
            变化     稳定         变化
            ↑ 破坏缓存
```
