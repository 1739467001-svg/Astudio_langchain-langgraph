# 多语言架构图解

> 用图解理解多语言应用的语言检测、翻译和跨语言 RAG 架构。

---

## 一、多语言应用场景

```mermaid
graph TB
    subgraph 多语言场景
        S1["🌐 多语言客服<br/>中/英/日/韩用户<br/>统一入口"]
        S2["🔄 翻译系统<br/>多语言互译<br/>带质量检查"]
        S3["📚 跨语言RAG<br/>中文查询→英文文档库<br/>中文回答"]
        S4["🌍 多语言内容<br/>一份内容→生成6种语言版本"]
    end

    style S1 fill:#E3F2FD
    style S2 fill:#FFF9C4
    style S3 fill:#FFE0B2
    style S4 fill:#F3E5F5
```

## 二、语言检测路由

```mermaid
graph TB
    U([用户输入]) --> DETECT["语言检测<br/>zh/en/ja/ko"]
    DETECT -->|"zh"| ZH["中文Agent<br/>用中文回复"]
    DETECT -->|"en"| EN["英文Agent<br/>用英文回复"]
    DETECT -->|"ja"| JA["日文Agent<br/>用日文回复"]
    DETECT -->|"其他"| FALL["翻译→英文处理→翻译回原语言"]

    style DETECT fill:#FFF9C4
    style FALL fill:#FFE0B2
```

## 三、跨语言 RAG 数据流

```mermaid
sequenceDiagram
    participant U as 用户
    participant D as 语言检测
    participant T as 翻译
    participant V as 向量库
    participant L as LLM

    U->>D: "量子计算的应用"（中文）
    D-->>D: 检测到 zh

    Note over D: 文档库语言: en
    D->>T: 翻译查询为英文
    T-->>D: "applications of quantum computing"

    D->>V: 用英文查询检索
    V-->>D: 找到英文文档片段

    D->>L: 英文上下文 + 中文原问题
    Note over L: 用中文生成回答
    L-->>U: "量子计算的应用包括..."
```

## 四、翻译 Agent 架构

```mermaid
graph TB
    START([输入文本]) --> TRANS["翻译节点<br/>LLM翻译"]
    TRANS --> REV["审查节点<br/>LLM评估翻译质量"]
    REV --> CHECK{"质量≥4分?"}
    CHECK -->|"否"| TRANS
    CHECK -->|"是"| OUT([输出译文])
    CHECK -->|"重试≥2次"| OUT

    style TRANS fill:#E3F2FD
    style REV fill:#FFF9C4
    style CHECK fill:#FFE0B2
    style OUT fill:#C8E6C9
```
