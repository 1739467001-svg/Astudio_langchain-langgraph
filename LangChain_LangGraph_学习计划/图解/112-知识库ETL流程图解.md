## 三、Transform流程

```mermaid
graph TB
    RAW["原始文档"] --> CLEAN["清洗<br/>去HTML/空白"]
    CLEAN --> SPLIT["分块<br/>递归字符"]
    SPLIT --> FILTER["过滤<br/>太小/太大"]
    FILTER --> ENRICH["元数据增强<br/>hash/来源"]
    ENRICH --> DEDUPE["去重<br/>内容哈希"]
    DEDUPE --> READY["可入库"]

    style CLEAN fill:#FFF9C4
    style SPLIT fill:#FFF3E0
    style DEDUPE fill:#C8E6C9
```
