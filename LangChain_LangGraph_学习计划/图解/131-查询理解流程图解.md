# 查询理解流程图解

> 用图解理解意图识别、查询改写和槽位提取的三层管线。

---

## 一、三层理解

```mermaid
graph TB
    L1["第1层: 意图识别<br/>'帮我看看'→什么意图?"] --> L2["第2层: 查询改写<br/>'这个'→指代消解"]
    L2 --> L3["第3层: 槽位提取<br/>订单号=? 日期=?"]

    style L1 fill:#E3F2FD,stroke:#1565C0,stroke-width:3px
```

---

## 二、意图分类

```mermaid
graph TB
    INPUT["用户输入"] --> CLASSIFY["意图分类"]
    CLASSIFY --> SEARCH["搜索"]
    CLASSIFY --> QA["问答"]
    CLASSIFY --> TASK["任务"]
    CLASSIFY --> CHAT["闲聊"]
    CLASSIFY --> CLARIFY["需澄清"]

    style CLASSIFY fill:#FFF9C4
```

---

## 三、查询改写场景

```mermaid
graph TB
    subgraph 改写 {"4种改写场景"}
        R1["指代消解: '这个'→'LangChain'"]
        R2["口语→书面: '咋用'→'如何使用'"]
        R3["补全上下文: '还有吗'→'还有其他方法吗'"]
        R4["多意图拆分: '查天气和订票'→2个查询"]
    end

    style 改写 fill:#E3F2FD
```

---

## 四、完整管线

```mermaid
graph TB
    Q["用户查询"] --> INTENT["意图识别"]
    INTENT --> REWRITE["查询改写"]
    REWRITE --> SLOTS["槽位提取"]
    SLOTS --> MISSING{"缺槽位?"}
    MISSING -->|是| CLARIFY["追问"]
    MISSING -->|否| ROUTE["按意图路由"]

    style INTENT fill:#FFF9C4
    style CLARIFY fill:#FFCDD2
    style ROUTE fill:#C8E6C9
```

---

## 五、与RAG集成

```mermaid
graph TB
    Q["查询"] --> UNDERSTAND["查询理解"]
    UNDERSTAND -->|搜索/QA| RETRIEVE["改写后检索"]
    UNDERSTAND -->|闲聊| DIRECT["直接回答"]
    UNDERSTAND -->|需澄清| CLARIFY["追问"]
    UNDERSTAND -->|任务| AGENT["Agent执行"]

    style UNDERSTAND fill:#FFF9C4
```
