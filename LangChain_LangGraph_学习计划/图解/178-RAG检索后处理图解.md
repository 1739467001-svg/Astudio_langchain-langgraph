# RAG 检索后处理图解

> 用图解理解去重、过滤、重排序和压缩。

---

## 一、后处理流程

```mermaid
graph LR
    RET["Top-10"] --> DEDUPE["去重"]
    DEDUPE --> FILTER["过滤"]
    FILTER --> RERANK["重排序"]
    RERANK --> COMPRESS["压缩"]
    COMPRESS --> FINAL["Top-3-5"]

    style DEDUPE fill:#E3F2FD
    style RERANK fill:#FFF9C4
    style FINAL fill:#C8E6C9
```
