# 指标采集与监控面板图解

> Counter+Histogram+Gauge三种指标→采集器→面板→告警规则。

---

```mermaid
graph TB
    AGENT["Agent执行"] --> COLLECT["指标采集器"]
    COLLECT --> C["Counter<br/>请求数/错误数"]
    COLLECT --> H["Histogram<br/>延迟分布/Token"]
    COLLECT --> G["Gauge<br/>并发数/队列"]
    C & H & G --> DASH["监控面板"]
    DASH --> ALERT{"告警规则"}
    ALERT --> NOTIFY["通知"]

    style COLLECT fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style DASH fill:#E3F2FD
    style ALERT fill:#FFE0B2
```

---

## 核心指标

| 指标 | 类型 | 告警阈值 |
|------|------|----------|
| 请求数 | Counter | - |
| 错误数 | Counter | 增量>0 |
| 延迟 | Histogram | p95>5s |
| Token | Histogram | 日>预算 |
| 并发 | Gauge | >max×0.8 |
