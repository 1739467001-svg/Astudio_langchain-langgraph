# 目标分解与任务规划图解

> 复合目标→分解为子任务→构建依赖图→按拓扑顺序执行→支持动态重规划。

---

```mermaid
graph TB
    GOAL["复合目标"] --> DECOMP["分解器"]
    DECOMP --> T1["t1: 搜索"]
    DECOMP --> T2["t2: 分析"]
    DECOMP --> T3["t3: 整理"]
    DECOMP --> T4["t4: 撰写"]
    T1 --> T2 --> T3 --> T4
    T4 --> DONE["完成"]

    style DECOMP fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style DONE fill:#C8E6C9
```

## 分解策略

| 策略 | 适用 | 特点 |
