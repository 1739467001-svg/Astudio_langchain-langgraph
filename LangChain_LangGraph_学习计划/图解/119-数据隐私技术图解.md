## 三、数据脱敏流程

```mermaid
graph LR
    INPUT["用户输入<br/>含PII"] → MASK["脱敏<br/>PII→占位符"]
    MASK → LLM["发送给LLM<br/>无PII"]
    LLM → RESPONSE["LLM返回"]
    RESPONSE → UNMASK["恢复占位符<br/>→原文"]
    UNMASK → OUTPUT["输出给用户"]

    style MASK fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style LLM fill:#E3F2FD
```
