# 端到端测试框架图解

> 测试套件→Mock环境→执行Agent→断言检查→CI门禁。

---

```mermaid
graph TB
    SUITE["测试套件"] --> RUN["执行Agent"]
    RUN --> ASSERT{"断言检查"}
    ASSERT -->|通过| PASS["✅"]
    ASSERT -->|失败| FAIL["❌"]
    PASS & FAIL --> REPORT["报告"]
    REPORT --> CI{"CI门禁"}
    CI -->|全通过| DEPLOY["部署"]
    CI -->|有失败| BLOCK["阻止"]

    style ASSERT fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style DEPLOY fill:#C8E6C9
    style BLOCK fill:#FFCDD2
```

---

## 断言类型

| 类型 | 精确度 | 适用 |
|------|--------|------|
| 关键词包含 | 中 | 事实问答 |
| 精确匹配 | 高 | 固定格式 |
| 工具调用检查 | 高 | 工具验证 |
| 响应时间 | 高 | 性能 |
| 语义匹配 | 高 | 复杂回答 |
