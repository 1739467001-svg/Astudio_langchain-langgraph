# 健康探针图解

> 存活探针回答"活着吗"，就绪探针回答"能干活吗"——双探针分离重启与摘流。

---

```mermaid
graph TB
    LB["负载均衡"] --> LIVE{"存活探针<br/>Liveness"}
    LIVE -->|是| READY{"就绪探针<br/>Readiness"}
    LIVE -->|否| RESTART["重启"]
    READY -->|是| ROUTE["分发流量"]
    READY -->|否| DRAIN["摘除流量"]

    style LIVE fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style READY fill:#E3F2FD,stroke:#1565C0
    style RESTART fill:#FFCDD2
    style ROUTE fill:#C8E6C9
```

---

## 探针配置

| 类型 | 间隔 | 超时 | 失败动作 |
|------|------|------|----------|
| Liveness | 30s | 5s | 重启 |
| Readiness | 10s | 3s | 摘流 |
| Startup | 5s | 30s | 阻流 |
