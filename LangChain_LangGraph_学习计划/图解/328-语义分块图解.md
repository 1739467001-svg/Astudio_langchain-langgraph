# 语义分块图解

> 不再"每500字符切一刀"——用嵌入相似度检测语义断点，让每个chunk语义完整。

---

```mermaid
graph TB
    TEXT["原始文本"] --> SPLIT["拆分为句子"]
    SPLIT --> EMBED["嵌入每个句子"]
    EMBED --> SIM["计算相邻相似度"]
    SIM --> BREAK{"相似度<br/>低于阈值?"}
    BREAK -->|是| CUT["在此断点切分"]
    BREAK -->|否| MERGE["合并到当前块"]
    CUT & MERGE --> CHUNK["语义完整的Chunk"]

    style SIM fill:#E3F2FD,stroke:#1565C0
    style BREAK fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style CHUNK fill:#C8E6C9
```

## 分块策略对比

| 策略 | 语义质量 | 速度 | 适用 |
|------|----------|------|------|
| 固定大小 | 差 | 极快 | 原型 |
| 递归分块 | 中 | 快 | 通用 |
| 语义分块 | 高 | 中 | 高质量RAG |
| 自适应 | 高 | 中 | 生产环境 |
