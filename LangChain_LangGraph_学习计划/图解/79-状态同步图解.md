# 多 Agent 状态同步图解

> 用图解理解并行 Agent 的状态同步和屏障机制。

---

## 一、并行同步问题

```mermaid
graph TB
    subgraph 问题 {"并行Agent状态不一致"}
        A1["A读x=1"] & B1["B读x=1"]
        A1 --> A2["A: x→2"]
        B1 --> B2["B: x→3"]
        A2 --> R["❌ B覆盖A的更新"]
        B2 --> R
    end

    style 问题 fill:'#FFCDD2'
```

## 二、LangGraph 解决方案

```mermaid
graph TB
    subgraph 解决 {"LangGraph并行同步"}
        S["START"] --> A["Agent A<br/>更新research_a"]
        S --> B["Agent B<br/>更新research_b"]
        A --> BARRIER["屏障: 自动等待<br/>A和B都完成"]
        B --> BARRIER
        BARRIER --> MERGE["合并节点<br/>看到所有结果"]
        MERGE --> END["END"]
    end

    style BARRIER fill:'#FFF9C4'
    style MERGE fill:'#C8E6C9'
```

## 三、Reducer 合并

```mermaid
graph TB
    subgraph Reducer {"Reducer自动合并"}
        A["A返回: research_a=['结果A']"]
        B["B返回: research_b=['结果B']"]
        A & B --> MERGE["Annotated[list, add]<br/>自动追加合并"]
        MERGE --> S["State:<br/>research_a=['结果A']<br/>research_b=['结果B']<br/>(各字段独立，不覆盖)"]
    end

    style MERGE fill:'#C8E6C9'
```

## 四、最佳实践

```mermaid
graph TB
    subgraph 原则 {"并行Agent三原则"}
        P1["1.不同字段<br/>各Agent更新不同字段<br/>避免覆盖"]
        P2["2.用Reducer<br/>共享字段用add<br/>自动追加"]
        P3["3.合并节点<br/>等所有并行完成<br/>再合并"]
    end

    style 原则 fill:'#E3F2FD'
```
