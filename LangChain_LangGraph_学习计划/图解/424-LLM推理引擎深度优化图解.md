# LLM 推理引擎深度优化图解

> 同一模型优化前后性能差100倍。本图解可视化六大优化技术和性能瓶颈诊断。

---

## 推理两阶段

```mermaid
graph LR
    INPUT["输入Prompt"] --> PREFILL["Prefill 预填充<br/>处理所有输入Token<br/>计算密集<br/>决定首Token延迟"]
    PREFILL --> DECODE["Decode 解码<br/>逐个生成Token<br/>内存密集<br/>决定吞吐量"]
    DECODE --> OUTPUT["输出"]

    style PREFILL fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
```

## 六大优化技术

```mermaid
graph TB
    OPT["推理优化"]

    OPT --> KV["KV Cache<br/>缓存历史KV<br/>避免重复计算"]
    OPT --> PAGE["PagedAttention<br/>分页管理KV<br/>显存利用率80-95%"]
    OPT --> BATCH["连续批处理<br/>动态加入/移除请求<br/>GPU满载"]
    OPT --> SPEC["推测解码<br/>小模型先猜<br/>大模型验证<br/>2-3x加速"]
    OPT --> QUANT["量化<br/>FP16→INT4/FP8<br/>省显存+加速"]
    OPT --> TP["张量并行<br/>多GPU分模型<br/>跑大模型"]

    style OPT fill:#E3F2FD,stroke:#1565C0,stroke-width:3px
    style PAGE fill:#C8E6C9,stroke:#2E7D32,stroke-width:2px
    style SPEC fill:#FFF9C4,stroke:#F9A825,stroke-width:2px
    style QUANT fill:#F3E5F5,stroke:#7B1FA2
```
