# 用户反馈闭环图解

> 收集→分析→改进→重新部署→再收集——持续改进循环。

---

```mermaid
graph TB
    USER["用户使用"] --> RESPONSE["Agent回答"]
    RESPONSE --> FB{"用户反馈"}
    FB -->|正| POS["正反馈库"]
    FB -->|负| NEG["负反馈库"]
    POS & NEG --> ANALYZE["分析+分类"]
    ANALYZE --> ACTION{"改进决策"}
    ACTION -->|Prompt| P["更新Prompt"]
    ACTION -->|工具| T["修复工具"]
    ACTION -->|知识| K["补充知识库"]
    ACTION -->|模型| M["换模型"]
    P & T & K & M --> DEPLOY["重新部署"]
    DEPLOY --> USER

    style FB fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style ANALYZE fill:#E3F2FD,stroke:#1565C0
    style DEPLOY fill:#C8E6C9
```

| 方式 | 收集率 | 质量 | 适用 |
|------|--------|------|------|
