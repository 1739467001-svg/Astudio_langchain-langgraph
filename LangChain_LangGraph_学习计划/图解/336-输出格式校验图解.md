# 输出格式校验图解

> LLM输出→提取JSON→解析→Schema校验→失败自动修复重试→降级兜底。

---

```mermaid
graph TB
    LLM["LLM输出"] --> EXTRACT["提取JSON<br/>去Markdown"]
    EXTRACT --> PARSE{"解析成功?"}
    PARSE -->|是| SCHEMA{"Schema校验"}
    PARSE -->|否| REPAIR["自动修复<br/>补括号/去多余"]
    REPAIR --> PARSE
    SCHEMA -->|通过| OK["输出结果"]
    SCHEMA -->|失败| RETRY{"重试<3?"}
    RETRY -->|是| LLM2["LLM+错误反馈"]
    RETRY -->|否| FALLBACK["降级默认"]
    LLM2 --> EXTRACT

    style PARSE fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style OK fill:#C8E6C9
    style FALLBACK fill:#FFCDD2,stroke:#C62828
    style REPAIR fill:#E3F2FD,stroke:#1565C0
```

## 约束方式对比

| 方式 | 可靠性 | 成本 | 适用 |
|------|--------|------|------|
| JSON Schema | 高 | 低 | 结构化 |
| Pydantic | 高 | 低 | Python |
| 提示工程 | 中 | 0 | 简单 |
| 多次采样 | 高 | 高 | 高可靠 |
