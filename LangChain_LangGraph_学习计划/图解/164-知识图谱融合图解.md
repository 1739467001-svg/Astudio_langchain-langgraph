# 知识图谱融合图解

> 用图解理解向量+图谱并行检索和结果融合。

---

## 一、融合架构

```mermaid
graph TB
    Q["查询"] --> VEC["向量检索"]
    Q --> GRAPH["图谱查询"]
    VEC --> MERGE["结果融合"]
    GRAPH --> MERGE
    MERGE --> CONFLICT{"冲突?"}
    CONFLICT -->|无| GEN["LLM生成"]
    CONFLICT -->|有| RESOLVE["图谱优先"]
    RESOLVE --> GEN

    style MERGE fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style GEN fill:#C8E6C9
```

---

## 二、融合策略

```mermaid
graph TB
    subgraph 策略 {"融合策略"}
        S1["向量结果: 语义相似<br/>置信度0.7"]
        S2["图谱结果: 关系精确<br/>置信度0.9"]
        S3["重叠: 合并增强<br/>置信度0.9+"]
    end

    style 策略 fill:#E3F2FD
```
