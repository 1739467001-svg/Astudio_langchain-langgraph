# 并发安全与锁机制图解

> 悲观锁先锁后操作，乐观锁先操作后检查，分布式锁跨进程。

---

```mermaid
graph TB
    REQ["并发请求"] --> SHARED{"共享状态<br/>需锁?"}
    SHARED -->|是| LOCK{"获取锁"}
    LOCK -->|成功| CRITICAL["临界区"]
    LOCK -->|失败| WAIT["等待"]
    CRITICAL --> RELEASE["释放"]
    SHARED -->|否| DIRECT["直接执行"]

    style SHARED fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style LOCK fill:#E3F2FD
    style CRITICAL fill:#C8E6C9
    style WAIT fill:#FFE0B2
```

---

## 锁类型对比

| 类型 | 原理 | 适用 |
|------|------|------|
| 悲观锁 | 先锁后操作 | 写频繁 |
| 乐观锁 | 先操作后检查 | 读多写少 |
| 分布式锁 | 跨进程 | 多实例 |
