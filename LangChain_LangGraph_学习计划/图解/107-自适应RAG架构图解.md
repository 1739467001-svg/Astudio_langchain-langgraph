# 自适应 RAG 架构图解

> 用图解理解 Self-RAG 反思机制、Corrective RAG 纠错流程和三种策略对比。

---

## 一、三种RAG策略对比

```mermaid
graph TB
    subgraph 基础 {"基础RAG"}
        BQ["查询"] --> BR["总是检索"] --> BG["生成<br/>不管质量"]
    end

    subgraph SelfRAG {"Self-RAG"}
        SQ["查询"] --> SD1{"需要检索？"}
        SD1 -->|是| SR["检索→评估→生成→验证"]
        SD1 -->|否| SG["直接生成"]
    end

    subgraph CRAG {"Corrective RAG"}
        CQ["查询"] --> CR["检索"] --> CG{"质量评估"}
        CG -->|高| CGEN["直接生成"]
        CG -->|中| CREF["精炼重检索"]
        CG -->|低| CWEB["Web补充"]
    end

    style 基础 fill:#FFCDD2
    style SelfRAG fill:#E3F2FD
    style CRAG fill:#C8E6C9
```

---

## 二、Self-RAG四反思

```mermaid
graph TB
    Q["查询"] --> T1["Retrieve?<br/>需要检索？"]
    T1 -->|是| RET["检索"]
    T1 -->|否| GEN["直接生成"]
    RET --> T2["IsRelevant?<br/>相关？"]
    T2 -->|否| RET
    T2 -->|是| GEN
    GEN --> T3["IsSupported?<br/>有依据？"]
    T3 -->|否| GEN
    T3 -->|是| T4["IsUseful?<br/>有用？"]
    T4 -->|否| GEN
    T4 -->|是| OUT["输出"]

    style T1 fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style T2 fill:#FFF9C4
    style T3 fill:#FFF9C4
    style T4 fill:#FFF9C4
    style OUT fill:#C8E6C9
```

---

## 三、Corrective RAG三级评估

```mermaid
graph TB
    RET["检索结果"] --> GRADE{"质量评分"}
    GRADE -->|高 ≥0.8| CORRECT["✅ 直接使用"]
    GRADE -->|中 0.5-0.8| AMB["⚠️ 精炼查询重检索"]
    GRADE -->|低 <0.5| INC["❌ Web搜索补充"]
    CORRECT & AMB & INC --> GEN["LLM生成"]

    style CORRECT fill:#C8E6C9
    style AMB fill:#FFF9C4
    style INC fill:#FFCDD2
```

## 四、LangGraph编排

```mermaid
graph TB
    START["START"] --> RET["检索"]
    RET --> GRADE["质量评估"]
    GRADE --> ROUTE{"需要Web？"}
    ROUTE -->|否| GEN["生成"]
    ROUTE -->|是| WEB["Web搜索"]
    WEB --> GEN
    GEN --> END["END"]

    style GRADE fill:#FFF9C4
    style ROUTE fill:#FFF3E0
    style GEN fill:#C8E6C9
```

## 五、效果对比

| 策略 | 召回率 | 幻觉率 | 延迟 | LLM调用 |
|------|--------|--------|------|---------|
| 基础RAG | 70% | 15% | 1x | 1次 |
| Self-RAG | 85% | 5% | 1.5x | 3-5次 |
| CRAG | 90% | 3% | 1.3x | 2-3次 |
