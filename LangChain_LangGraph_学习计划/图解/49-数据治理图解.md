# 数据治理图解

> 用图解理解 RAG 知识库的数据治理框架。

---

## 一、治理五维度

```mermaid
graph TB
    subgraph 五维 {"RAG数据治理五维度"}
        D1["📐 质量<br/>准确/完整/无冗余"]
        D2["🔄 时效<br/>更新/清理/新鲜度"]
        D3["🏷️ 目录<br/>分类/标签/可检索"]
        D4["👤 权限<br/>谁可以看什么"]
        D5["📋 审计<br/>谁改了什么/何时"]
    end

    style 五维 fill:'#E3F2FD'
```

## 二、数据生命周期

```mermaid
graph LR
    C["收集"] --> V["审核"]
    V --> I["入库"]
    I --> U["使用"]
    U --> M["监控"]
    M --> R["更新/归档"]
    R --> C

    style C fill:'#C8E6C9'
    style R fill:'#FFE0B2'
```
