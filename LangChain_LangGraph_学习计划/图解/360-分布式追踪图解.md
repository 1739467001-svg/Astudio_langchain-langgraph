# 分布式追踪与调用图谱图解

> trace_id贯穿所有服务，parent_span_id构建调用树，一图看全链路。

---

```mermaid
graph TB
    GW["API网关<br/>trace=abc"] --> AGENT["Agent服务<br/>parent=gw"]
    AGENT --> LLM["LLM服务<br/>parent=agent"]
    AGENT --> VEC["向量库<br/>parent=agent"]
    AGENT --> TOOL["工具服务<br/>parent=agent"]
    LLM --> CACHE["缓存<br/>parent=llm"]

    GW & AGENT & LLM & VEC & TOOL & CACHE --> COLLECTOR["追踪收集器"]
    COLLECTOR --> GRAPH["调用图谱"]

    style GW fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style COLLECTOR fill:#E3F2FD
    style GRAPH fill:#C8E6C9
```

---

## 追踪字段

| 字段 | 说明 | 示例 |
|------|------|------|
| trace_id | 全局ID | abc123 |
| span_id | 本Span | def456 |
| parent_id | 父Span | abc123 |
| service | 服务名 | llm-service |
| duration_ms | 耗时 | 350 |
