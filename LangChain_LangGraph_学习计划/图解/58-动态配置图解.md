# 动态配置图解

> 用图解理解 LLM 应用的动态配置管理和功能开关。

---

## 一、静态 vs 动态配置

```mermaid
graph TB
    subgraph 静态 {"静态配置（.env）"}
        S1["修改→重启服务→生效"]
        S1 --> S2["❌ 需要停机"]
    end

    subgraph 动态 {"动态配置（JSON文件/API）"}
        D1["修改文件→自动热加载"]
        D1 --> D2["✅ 不停机 ✅ 灰度"]
    end

    style 静态 fill:'#FFCDD2'
    style 动态 fill:'#C8E6C9'
```

## 二、动态配置架构

```mermaid
graph TB
    subgraph 架构 {"动态配置架构"}
        F["config/dynamic.json"] --> CONFIG["DynamicConfig管理器"]
        CONFIG --> APP["应用代码"]
        APP --> LLM_PARAM["LLM参数<br/>(model/temp/max_tokens)"]
        APP --> RAG_PARAM["RAG参数<br/>(k/chunk_size)"]
        APP --> FLAGS["Feature Flags<br/>(streaming/guardrails/feedback)"]

        ADMIN["运维修改"] -.-> F
    end

    style CONFIG fill:'#FFF9C4'
    style ADMIN fill:'#E3F2FD'
```

## 三、Feature Flags

```mermaid
graph TB
    subgraph 功能开关 {"Feature Flags 功能开关"}
        F1["streaming<br/>✅ 流式输出 开"]
        F2["guardrails<br/>✅ 护栏 开"]
        F3["feedback<br/>✅ 反馈按钮 开"]
        F4["multimodal<br/>❌ 多模态 关"]
    end

    style F1 fill:'#C8E6C9'
    style F4 fill:'#FFCDD2'
```

```python
# 运维通过修改JSON文件控制功能
# 不需要重启服务
config.set("feature_flags.streaming", False)  # 临时关闭流式
config.set("model", "gpt-4o")  # 临时升级模型
```
