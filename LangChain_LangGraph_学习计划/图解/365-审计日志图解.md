# 审计日志与合规追溯图解

> 决策日志+工具日志+输出日志+用户日志→链式哈希不可篡改→追溯查询。

---

```mermaid
graph TB
    AGENT["Agent执行"] --> LOG["审计记录器"]
    LOG --> D1["决策日志"]
    LOG --> D2["工具日志"]
    LOG --> D3["输出日志"]
    LOG --> D4["用户日志"]
    D1 & D2 & D3 & D4 --> STORE["链式哈希存储"]
    STORE --> QUERY["追溯查询"]
    STORE --> REPORT["合规报告"]

    style LOG fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style STORE fill:#E3F2FD
    style REPORT fill:#C8E6C9
```

---

## 审计字段

| 字段 | 必填 | 示例 |
|------|------|------|
| entry_id | 是 | audit-001 |
| action | 是 | tool_call |
| user_id | 是 | user123 |
| input_summary | 否 | 已脱敏 |
| hash | 是 | a1b2c3 |
