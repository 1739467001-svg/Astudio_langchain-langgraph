# 对话状态跟踪图解

> 用图解理解对话状态机模型、槽位填充流程和状态转移。

---

## 一、为什么需要状态跟踪

```mermaid
graph TB
    subgraph 无状态 {"无状态对话"}
        U1["订票"] --> A1["好的"]
        U2["选座位"] --> A2["❌ 哪张票？"]
    end

    subgraph 有状态 {"有状态对话"}
        U3["订票"] --> DST1["DST: intent=book<br/>from=北京,to=上海"]
        U4["选座位"] --> DST2["DST: +seat=window"]
        U5["付款"] --> DST3["DST: +pay=card"]
    end

    style 无状态 fill:#FFCDD2
    style 有状态 fill:#C8E6C9
```

## 二、对话状态机

```mermaid
graph TB
    IDLE["空闲态<br/>识别意图"] --> COLLECTING["收集态<br/>填充槽位"]
    COLLECTING --> CONFIRMING["确认态<br/>用户确认"]
    CONFIRMING --> EXECUTING["执行态<br/>调用API"]
    EXECUTING --> COMPLETED["完成态"]
    CONFIRMING -->|修改| COLLECTING
    EXECUTING -->|失败| COLLECTING
    COMPLETED --> IDLE

    style IDLE fill:#E3F2FD
    style COLLECTING fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style CONFIRMING fill:#FFF3E0
    style EXECUTING fill:#F3E5F5
    style COMPLETED fill:#C8E6C9
```

---

## 三、槽位填充流程

```mermaid
graph TB
    INPUT["用户输入"] --> IDENTIFY["识别意图"]
    IDENTIFY --> SLOTS["初始化槽位模板"]
    SLOTS --> EXTRACT["从输入提取已填槽位"]
    EXTRACT --> CHECK{"所有必需<br/>槽位已填？"}
    CHECK -->|否| ASK["询问下一个未填槽位"]
    ASK --> INPUT
    CHECK -->|是| CONFIRM["转入确认态"]

    style EXTRACT fill:#FFF9C4
    style CHECK fill:#FFF3E0
    style CONFIRM fill:#C8E6C9
```

---

## 四、确认与执行

```mermaid
graph TB
    CONFIRM["确认态"] --> INPUT{"用户回应"}
    INPUT -->|确认| EXEC["执行操作"]
    INPUT -->|修改| COLLECT["回到收集态"]
    INPUT -->|不明确| REASK["重新询问"]
    EXEC --> RESULT["返回结果"]
    RESULT --> IDLE["回到空闲态"]

    style EXEC fill:#C8E6C9
    style COLLECT fill:#FFF9C4
```

## 五、对话示例

```mermaid
sequenceDiagram
    participant U as 用户
    participant E as 引擎

    U->>E: 订北京到上海的机票
    E->>E: 意图=book_flight, 填充from=北京,to=上海
    E-->>U: 出发日期是哪天？
    U->>E: 明天
    E->>E: 填充date=明天
    E-->>U: 乘客姓名？
    U->>E: 张三
    E->>E: 填充passenger=张三
    E-->>U: 请确认...
    U->>E: 确认
    E->>E: 执行订票
    E-->>U: 订票成功
```
