```mermaid
    Note over L: 两个工具结果都有了<br/>信息足够回答
    L-->>AE: AIMessage(content="北京今天晴25°C，3×5=15")
    Note over L: 无tool_calls → 最终回答

    AE-->>U: "北京今天晴25°C，3×5=15"
```

## 八、工具调用失败的错误处理

```mermaid

        RESULT -->|"成功"| OK["ToolMessage(content=结果)"]
        RESULT -->|"参数错误"| E1["ToolMessage(content='参数错误:...')<br/>LLM可能重新调用"]
        RESULT -->|"工具异常"| E2["ToolMessage(content='执行失败:...')<br/>LLM可能换工具或直接回答"]
        RESULT -->|"超时"| E3["ToolMessage(content='工具超时')<br/>LLM可能换工具"]
    end

    style OK fill:#C8E6C9
    style E1 fill:#FFE0B2
    style E2 fill:#FFCDD2
    style E3 fill:#FFCDD2
```

```python
# 错误处理的工具实现
@tool
def safe_api_call(endpoint: str, params: dict) -> str:
    """调用外部API。"""
    import requests
    try:
        response = requests.get(endpoint, params=params, timeout=10)
        response.raise_for_status()
        return response.text
    except requests.Timeout:
        return "错误: API调用超时，请稍后重试或换一种方式"
    except requests.ConnectionError:
        return "错误: 无法连接到服务器，可能网络问题"
    except Exception as e:
        return f"错误: {type(e).__name__}: {str(e)}"
```
