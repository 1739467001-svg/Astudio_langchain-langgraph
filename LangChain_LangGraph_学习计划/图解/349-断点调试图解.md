# 断点调试与步骤回放图解

> 节点前暂停→查看状态→修改后继续→回放历史——像调试器一样调试LangGraph。

---

```mermaid
graph TB
    START((开始)) --> N1["节点A"]
    N1 --> PAUSE{"⏸ 断点"}
    PAUSE -->|查看状态| VIEW["查看State+next"]
    PAUSE -->|修改状态| MOD["update_state"]
    PAUSE -->|继续| N2["节点B"]
    N2 --> PAUSE2{"⏸ 断点"}
    PAUSE2 -->|回放| HISTORY["快照历史"]
    PAUSE2 -->|继续| END((结束))

    style PAUSE fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style VIEW fill:#E3F2FD
    style HISTORY fill:#F3E5F5
```

---

## 调试方式

| 方式 | 实现 | 适用 |
|------|------|------|
| interrupt_before | 编译时指定 | 固定断点 |
| interrupt_after | 节点后暂停 | 查输出 |
| 动态interrupt | 运行时判断 | 条件断点 |
| 快照回放 | get_state_history | 事后分析 |
