# 可解释性架构图解

> 用图解理解 Agent 决策可解释性的三层模型。

---

## 一、黑盒 vs 可解释

```mermaid
graph TB
    subgraph 黑盒 {"❌ 黑盒Agent"}
        U1["用户"] --> A1["Agent(不透明)"]
        A1 --> R1["回答(不知为什么)"]
    end

    subgraph 可解释 {"✅ 可解释Agent"}
        U2["用户"] --> A2["Agent"]
        A2 --> D1["决策记录"]
        D1 --> R2["回答+决策链"]
    end

    style 黑盒 fill:'#FFCDD2'
    style 可解释 fill:'#C8E6C9'
```

## 二、三层可解释性

```mermaid
graph TB
    subgraph 三层 {"可解释性三个层次"}
        L1["Level 1: 执行追踪<br/>记录用了什么工具/什么参数<br/>实现: Callback"]
        L2["Level 2: 决策理由<br/>记录为什么选这个工具<br/>实现: Prompt要求LLM输出理由"]
        L3["Level 3: 对话式解释<br/>用户可追问'为什么'<br/>实现: 决策记录+LLM解释"]
    end

    L1 --> L2 --> L3

    style L1 fill:'#C8E6C9'
    style L3 fill:'#F3E5F5'
```

## 三、决策追踪结构

```mermaid
graph TB
    subgraph 追踪 {"决策追踪结构"}
        T["DecisionTrace"]
        T --> Q["question: 用户问题"]
        T --> DS["decisions: 决策列表"]
        T --> FA["final_answer: 最终回答"]
        T --> M["metrics: 步数/Token/耗时"]

        DS --> D1["Step1: 思考→工具选择→执行→结果"]
        DS --> D2["Step2: 思考→工具选择→执行→结果"]
        DS --> DN["StepN: 最终回答"]
    end

    style 追踪 fill:'#E3F2FD'
```

## 四、可解释报告

```mermaid
graph TB
    subgraph 报告 {"可解释报告示例"}
        R1["=== Agent决策追踪 ==="]
        R1 --> R2["问题: 查ORD001状态"]
        R2 --> R3["Step1: 🧠识别为订单查询<br/>🔧工具: query_order<br/>📥输入: ORD001<br/>👀结果: 已发货"]
        R3 --> R4["最终回答: 订单已发货..."]
        R4 --> R5["步数:1 Token:350 耗时:2.8s"]
    end

    style 报告 fill:'#C8E6C9'
```
