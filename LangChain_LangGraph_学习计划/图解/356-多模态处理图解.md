# 多模态输入输出图解

> 图片+文本→多模态LLM→文本/图片输出。OCR、图问答、多图对比、文生图。

---

```mermaid
graph TB
    INPUT["用户输入"] --> CLS{"类型?"}
    CLS -->|纯文本| TEXT["文本处理"]
    CLS -->|图文| IMG["图像理解"]
    CLS -->|多图| MULTI["多图对比"]
    TEXT & IMG & MULTI --> LLM["多模态LLM<br/>GPT-4o"]
    LLM --> OUT{"输出?"}
    OUT -->|文本| TXT["文本回答"]
    OUT -->|图片| GEN["DALL-E生成"]

    style CLS fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style LLM fill:#E3F2FD
    style GEN fill:#F3E5F5
```

---

## 多模态场景

| 场景 | 输入 | 输出 | 难度 |
|------|------|------|------|
| 图问答 | 图+文本 | 文本 | 中 |
| OCR | 图 | 文本 | 中 |
| 多图对比 | 多图 | 文本 | 高 |
| 文生图 | 文本 | 图 | 中 |
