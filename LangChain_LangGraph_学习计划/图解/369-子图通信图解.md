# LangGraph 子图通信与消息传递图解

> 子图作为父图节点运行，通过状态映射与父图交换数据。

---

```mermaid
graph TB
    subgraph 父图
        S["START"] --> R["研究子图节点"]
        R --> W["写作子图节点"]
        W --> E["END"]
    end

    subgraph 研究子图
        R1["检索"] --> R2["过滤"] --> R3["总结"]
    end

    subgraph 写作子图
        W1["大纲"] --> W2["撰写"] --> W3["校对"]
    end

    R -.->|"状态映射→"| R1
    R3 -.->|"←结果映射"| R
    W -.->|"状态映射→"| W1
    W3 -.->|"←结果映射"| W

    style R fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style W fill:#E3F2FD,stroke:#1565C0
    style R3 fill:#C8E6C9
    style W3 fill:#C8E6C9
```

---

## 通信模式对比

| 模式 | 原理 | 适用 |
|------|------|------|
| 状态映射 | 父图节点手动转换 | 字段不匹配 |
| 共享状态 | 相同TypedDict | 字段重叠 |
| 消息传递 | messages列表 | 对话型 |
| 通道映射 | reducer合并 | 多子图并行 |
