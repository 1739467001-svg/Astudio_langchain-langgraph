# 容量规划图解

> 用图解理解 LLM 应用的容量估算和扩展策略。

---

## 一、关键指标

```mermaid
graph TB
    subgraph 指标 {"容量规划四指标"}
        I1["QPS<br/>每秒查询数<br/>决定实例数"]
        I2["并发数<br/>同时处理请求<br/>决定Worker数"]
        I3["延迟P95<br/>用户体验<br/>决定是否优化"]
        I4["API额度<br/>日/月限额<br/>决定成本上限"]
    end

    style 指标 fill:'#E3F2FD'
```

## 二、规模与资源

```mermaid
graph TB
    subgraph 资源 {"不同规模资源需求"}
        S["小型<br/>100用户/天<br/>2核4GB<br/>1实例<br/>FAISS<br/>~$3/月"]
        M["中型<br/>1000用户/天<br/>4核8GB<br/>2实例<br/>Chroma<br/>~$15/月"]
        L["大型<br/>10000用户/天<br/>8核×2<br/>4+实例<br/>Milvus<br/>~$80/月"]
    end

    S --> M --> L

    style S fill:'#C8E6C9'
    style L fill:'#FFE0B2'
```

## 三、扩展路径

```mermaid
graph LR
    subgraph 扩展 {"从单机到集群"}
        A["单机<br/>1实例<br/>FAISS+SQLite"] --> B["双机<br/>2实例+Nginx<br/>Chroma+PostgreSQL"]
        B --> C["集群<br/>K8s自动扩缩<br/>Milvus+PG主从"]
        C --> D["全球<br/>多区域+CDN<br/>Pinecone云托管"]
    end

    style A fill:'#C8E6C9'
    style D fill:'#F3E5F5'
```

## 四、QPS估算

```mermaid
graph TB
    subgraph 估算 {"QPS估算方法"}
        U["日活用户: 500"] --> C["每人每天调用: 10次"]
        C --> D["日总调用: 5000"]
        D --> AVG["平均QPS: 0.1"]
        AVG --> PEAK["峰值QPS: 0.3(×3)"]
        PEAK --> INS["需要实例: 1(每实例5QPS)"]
    end

    style 估算 fill:'#E3F2FD'
```
