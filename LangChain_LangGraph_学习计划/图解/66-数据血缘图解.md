# 数据血缘图解

> 用图解理解从原始文档到最终回答的完整数据血缘链路。

---

## 一、血缘链路

```mermaid
graph LR
    subgraph 血缘 {"完整数据血缘链路"}
        D["📄 原始文档<br/>manual.pdf"] --> S["✂️ 分割<br/>chunk3"]
        S --> E["🔢 向量化<br/>向量[0.1,...]"]
        E --> R["🔍 检索<br/>Top-3"]
        R --> A["📝 上下文组装<br/>+来源标注"]
        A --> L["🤖 LLM生成<br/>回答"]
        L --> OUT["📋 回答+引用来源"]
    end

    style 血缘 fill:'#E3F2FD'
```

## 二、无溯源 vs 有溯源

```mermaid
graph TB
    subgraph 无溯源 {"❌ 无溯源"}
        A1["回答: '防水等级IPX5'"]
        N1["用户: '基于什么？'<br/>→ '不知道'"]
    end

    subgraph 有溯源 {"✅ 有溯源"}
        A2["回答: '防水等级IPX5'"]
        A2 --> S2["来源: product_manual.pdf 第3页<br/>chunk_id: chunk_7"]
    end

    style 无溯源 fill:'#FFCDD2'
    style 有溯源 fill:'#C8E6C9'
```
