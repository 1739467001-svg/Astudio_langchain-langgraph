# 环境配置指南

> 详细的环境搭建步骤，覆盖不同操作系统和常见配置场景。

---

## 一、Python 安装

### 1.1 各平台安装

#### macOS

```bash
# 方式一：Homebrew（推荐）
brew install python@3.11

# 方式二：官网下载
# 前往 https://www.python.org/downloads/ 下载安装包

# 验证
python3 --version  # 应输出 Python 3.11.x
```

#### Windows

```powershell
# 1. 前往 https://www.python.org/downloads/ 下载
# 2. 运行安装程序
# 3. ⚠️ 务必勾选 "Add Python to PATH"
# 4. 选择 "Install Now"

# 验证（打开 PowerShell）
python --version
pip --version
```

#### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
python3 --version
```

### 1.2 推荐版本

| 版本 | 状态 | 推荐度 |
|------|------|--------|
| Python 3.9 | 兼容 | ✅ 最低要求 |
| Python 3.11 | 兼容 | ✅ 推荐（性能好） |
| Python 3.12 | 兼容 | ✅ 推荐 |
| Python 3.13+ | 大部分兼容 | ⚠️ 少数包可能未适配 |

## 二、虚拟环境

### 2.1 使用 venv（内置）

```bash
# 创建虚拟环境
python -m venv venv

# 激活
# macOS / Linux:
source venv/bin/activate
# Windows (PowerShell):
venv\Scripts\Activate.ps1
# Windows (CMD):
venv\Scripts\activate.bat

# 退出虚拟环境
deactivate
```

### 2.2 使用 conda（可选）

```bash
# 创建环境
conda create -n langchain-env python=3.11

# 激活
conda activate langchain-env

# 退出
conda deactivate
```

### 2.3 常见问题

**Windows PowerShell 执行策略错误：**

```powershell
# 如果遇到 "无法加载文件...因为在此系统上禁止运行脚本"
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**macOS python 命令找不到：**

```bash
# macOS 上可能需要用 python3 而不是 python
# 可以创建别名
echo 'alias python=python3' >> ~/.zshrc
source ~/.zshrc
```

## 四、API Key 配置

### 4.1 OpenAI

1. 注册账号：[platform.openai.com](https://platform.openai.com)
2. 创建 API Key：Account → API Keys → Create new secret key
3. 充值：需要绑定支付方式并充值（至少 $5）
4. 配置 `.env` 文件：

```env
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
```

### 4.2 Anthropic Claude

```env
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxx
```

```bash
pip install langchain-anthropic
```

### 4.3 科大讯飞星火

```env
IFLYTEK_APP_ID=你的APP_ID
IFLYTEK_API_KEY=你的API_KEY
IFLYTEK_API_SECRET=你的API_SECRET
```

### 4.4 阿里云通义千问

```env
DASHSCOPE_API_KEY=你的密钥
```

```bash
pip install dashscope
```

### 4.5 Ollama（本地模型，免费）

1. 安装 Ollama：[ollama.com](https://ollama.com)
2. 下载模型：

```bash
ollama pull llama3        # Meta Llama 3
ollama pull qwen2         # 通义千问
ollama pull mistral       # Mistral
```

3. 安装 Python 包：

```bash
pip install langchain-ollama
```

4. 使用：

```python
from langchain_ollama import ChatOllama
llm = ChatOllama(model="llama3")  # 不需要 API Key
```

### 4.6 安全规范

```bash
# ⚠️ 永远不要把 .env 文件提交到 git
# 确保项目根目录有 .gitignore 文件

# .gitignore 内容
echo ".env" >> .gitignore
echo "venv/" >> .gitignore
echo "__pycache__/" >> .gitignore
echo "*.pyc" >> .gitignore
```

### 5.3 LangSmith 配置（可选但推荐）

1. 注册：[smith.langchain.com](https://smith.langchain.com)
2. 获取 API Key
3. 配置 `.env`：

```env
LANGSMITH_API_KEY=你的密钥
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=my-learning-project
```

配置后，所有 LangChain 调用会自动上报到 LangSmith，可以在网页上查看完整的调用链。

## 六、验证安装

创建 `test_setup.py`：

```python
"""验证环境是否配置正确"""

def test_imports():
    """测试导入"""
    from langchain_core.prompts import ChatPromptTemplate
    from langchain_core.messages import HumanMessage, AIMessage
    from langchain_core.output_parsers import StrOutputParser
    from langchain_openai import ChatOpenAI, OpenAIEmbeddings
    from langchain_community.vectorstores import FAISS
    from langchain_text_splitters import RecursiveCharacterTextSplitter
    from langgraph.graph import StateGraph, START, END
    print("✅ 所有包导入成功")

def test_llm():
    """测试 LLM 调用"""
    from dotenv import load_dotenv
    from langchain_openai import ChatOpenAI
    load_dotenv()
    llm = ChatOpenAI(model="gpt-4o-mini")
    r = llm.invoke("回复OK")
    assert "ok" in r.content.lower() or "OK" in r.content
    print("✅ LLM 调用成功")

def test_embeddings():
    """测试向量化"""
    from dotenv import load_dotenv
    from langchain_openai import OpenAIEmbeddings
    load_dotenv()
    emb = OpenAIEmbeddings()
    v = emb.embed_query("test")
    assert len(v) > 0
    print(f"✅ 向量化成功（维度: {len(v)}）")

def test_langgraph():
    """测试 LangGraph"""
    from typing import TypedDict
    from langgraph.graph import StateGraph, START, END
    
    class S(TypedDict):
        value: str
    
    def node(state: S) -> dict:
        return {"value": state["value"] + "!"}
    
    g = StateGraph(S)
    g.add_node("node", node)
    g.add_edge(START, "node")
    g.add_edge("node", END)
    app = g.compile()
    r = app.invoke({"value": "test"})
    assert r["value"] == "test!"
    print("✅ LangGraph 工作正常")

if __name__ == "__main__":
    print("开始验证...\n")
    try:
        test_imports()
    except Exception as e:
        print(f"❌ 导入失败: {e}")
    
    try:
        test_llm()
    except Exception as e:
        print(f"❌ LLM 调用失败: {e}")
    
    try:
        test_embeddings()
    except Exception as e:
        print(f"❌ 向量化失败: {e}")
    
    try:
        test_langgraph()
    except Exception as e:
        print(f"❌ LangGraph 失败: {e}")
    
    print("\n验证完成。")
```

运行：

```bash
python test_setup.py
```

全部显示 ✅ 则环境配置完成。
