### 2.1 FastAPI 健康端点

```python
from fastapi import FastAPI
from langchain_openai import ChatOpenAI

app = FastAPI()
llm = ChatOpenAI(model="gpt-4o-mini", max_retries=1, timeout=5)

# Liveness: 应用进程是否活着（不检查依赖）
@app.get("/health/live")
async def liveness():
    """存活探针：只要进程在就返回200"""
    return {"status": "alive"}

# Readiness: 应用是否准备好接收流量（检查依赖）
@app.get("/health/ready")
async def readiness():
    """就绪探针：检查LLM API是否可用"""
    try:
        response = llm.invoke("ping")
        if response.content:
            return {"status": "ready", "model": "available"}
    except Exception as e:
        return {"status": "not_ready", "error": str(e)}, 503
    return {"status": "ready"}
```

### 2.2 K8s 探针配置

```yaml
# k8s deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: llm-app
spec:
  replicas: 3
  template:
    spec:
      containers:
      - name: app
        image: llm-app:v1.1
        livenessProbe:
          httpGet:
            path: /health/live
            port: 8000
          initialDelaySeconds: 5
          periodSeconds: 10
          failureThreshold: 3
        readinessProbe:
          httpGet:
            path: /health/ready
            port: 8000
          initialDelaySeconds: 10
          periodSeconds: 5
          failureThreshold: 2
```
