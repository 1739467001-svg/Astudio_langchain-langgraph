# 常见问题与排错指南

> 遇到问题时先看这里。按问题类型分类，附解决方案。

---

## 一、安装与导入问题

### Q1: `ModuleNotFoundError: No module named 'langchain'`

**原因**：LangChain 未安装，或虚拟环境未激活。

**解决**：

```bash
# 确认虚拟环境已激活（命令行前有 (venv) 标志）
pip install langchain langchain-openai langchain-community

# 如果已安装但仍报错，尝试
pip install --upgrade langchain
```

### Q2: `ModuleNotFoundError: No module named 'langchain_community'`

**原因**：v0.2+ 将社区集成拆分到了独立包。

**解决**：

```bash
pip install langchain-community
```

### Q3: `ModuleNotFoundError: No module named 'langgraph'`

**解决**：

```bash
pip install langgraph
```

### Q4: `ImportError: cannot import name 'XXX' from 'langchain'`

**原因**：LangChain 版本更新后，部分导入路径已变更。

**排查步骤**：

1. 检查当前版本：`pip show langchain`
2. 对照 [API 参考与速查手册](04-API参考与速查手册.md) 确认正确的导入路径
3. 常见的迁移：
   - `from langchain.chat_models import ChatOpenAI` → `from langchain_openai import ChatOpenAI`
   - `from langchain.embeddings import OpenAIEmbeddings` → `from langchain_openai import OpenAIEmbeddings`
   - `from langchain.vectorstores import FAISS` → `from langchain_community.vectorstores import FAISS`
   - `from langchain.text_splitter import ...` → `from langchain_text_splitters import ...`

## 二、API Key 与认证问题

### Q5: `AuthenticationError: Incorrect API key provided`

**原因**：API Key 无效或未正确加载。

**排查步骤**：

```python
# 1. 确认 .env 文件在项目根目录
# 2. 确认 .env 文件格式正确（无引号、无空格）
# 正确格式：
# OPENAI_API_KEY=sk-xxxx

# 3. 验证加载
from dotenv import load_dotenv
import os
load_dotenv()
key = os.getenv("OPENAI_API_KEY")
print(f"Key 前缀: {key[:7] if key else '未找到'}")
print(f"Key 长度: {len(key) if key else 0}")
```

### Q6: `RateLimitError: You exceeded your current quota`

**原因**：API 额度用完或请求过于频繁。

**解决**：

1. 检查 OpenAI 账户余额：platform.openai.com → Billing
2. 设置重试：`llm = ChatOpenAI(model="gpt-4o-mini", max_retries=3)`
3. 使用更便宜的模型：`gpt-4o-mini` 比 `gpt-4o` 便宜很多
4. 启用缓存避免重复调用

### Q7: `ConnectionError: Error communicating with OpenAI`

**原因**：网络连接问题，可能需要代理。

**解决**：

```python
# 方式一：使用代理
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4o-mini",
    openai_api_base="https://你的代理地址/v1",
)

# 方式二：使用环境变量
# 在 .env 中设置
# OPENAI_API_BASE=https://你的代理地址/v1

# 方式三：换用国内模型（如通义千问、星火）
```

## 三、LLM 调用问题

### Q8: LLM 回复内容不符合预期

**排查方向**：

1. **Prompt 不够清晰**：加入明确的指令和示例
2. **temperature 过高**：尝试降到 0-0.3
3. **上下文不足**：检查传入的消息历史是否完整
4. **模型能力不足**：试试更强的模型

```python
# 调试：打印发送给 LLM 的实际内容
prompt = ChatPromptTemplate.from_messages([...])
formatted = prompt.invoke({"input": "test"})
print(formatted.to_messages())  # 看看实际发了什么
```

### Q9: `InvalidRequestError: maximum context length exceeded`

**原因**：输入文本超过了模型的上下文窗口。

**解决**：

1. 减少输入长度（精简 Prompt 或减少历史消息）
2. 使用更大上下文窗口的模型
3. 在 RAG 中减小 `chunk_size` 或 `k`（检索数量）
4. 实现对话历史截断策略

```python
# 截断历史消息
def trim_history(messages, max_messages=20):
    return messages[-max_messages:]
```

### Q10: Tool Calling 不生效

**原因**：不是所有模型都支持 Tool Calling。

**支持 Tool Calling 的模型**：

- OpenAI: GPT-4o, GPT-4o-mini, GPT-4-turbo
- Anthropic: Claude 3.5 Sonnet, Claude 3 Opus
- 部分本地模型（通过 Ollama）

```python
# 验证模型是否支持工具调用
llm = ChatOpenAI(model="gpt-4o-mini")
llm_with_tools = llm.bind_tools([my_tool])

# 查看模型返回的 tool_calls
response = llm_with_tools.invoke("帮我算一下 2+3")
print(response.tool_calls)  # 如果为空，说明模型没有调用工具
```

## 四、RAG 问题

### Q11: 检索结果不相关

**排查方向**：

1. **chunk_size 不合适**：尝试 300-500
2. **chunk_overlap 太小**：增加到 50-100
3. **文档质量**：检查原始文档是否包含目标信息
4. **Embedding 模型**：确保使用了合适的嵌入模型
5. **查询方式**：尝试改写用户问题

```python
# 调试：查看检索到了什么
results = db.similarity_search("query", k=3)
for i, doc in enumerate(results):
    print(f"--- 结果 {i+1} ---")
    print(doc.page_content[:200])
    print(doc.metadata)
```

### Q12: `FAISS.load_local` 报安全警告

**原因**：FAISS 反序列化有安全风险，v0.2+ 需要显式确认。

**解决**：

```python
db = FAISS.load_local(
    "my_index",
    embeddings,
    allow_dangerous_deserialization=True  # 加上这个参数
)
```

### Q13: 中文文档检索效果差

**解决**：

1. 确保分割时考虑中文标点

```python
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=50,
    separators=["\n\n", "\n", "。", "！", "？", "；", "，", " ", ""]
)
```

2. 使用对中文友好的 Embedding 模型

## 五、LangGraph 问题

### Q14: 图编译报错 `ValueError: Node 'xxx' not found`

**原因**：`add_edge` 引用了未添加的节点。

**解决**：确保 `add_node` 在 `add_edge` 之前执行。

```python
# ✅ 正确顺序
graph.add_node("a", func_a)  # 先添加节点
graph.add_node("b", func_b)
graph.add_edge("a", "b")     # 再添加边
graph.add_edge(START, "a")
graph.add_edge("b", END)

# ❌ 错误：边引用了不存在的节点
# graph.add_edge("a", "b")
# graph.add_node("a", func_a)  # 顺序错了
```

### Q15: 图运行时无限循环

**原因**：条件边形成了循环，但缺少退出条件。

**解决**：

1. 添加最大尝试次数限制
2. 确保路由函数有明确的退出路径

```python
def route(state) -> str:
    # 必须有退出路径
    if state["attempts"] >= 5:  # 最大重试
        return "done"
    if state["result"]:  # 有结果了
        return "done"
    return "retry"  # 否则重试
```

### Q16: State 字段更新不符合预期

**原因**：不理解 Reducer 机制。

**排查**：

```python
from typing import TypedDict, Annotated
from operator import add

class State(TypedDict):
    # Annotated[list, add] → 追加（不是替换）
    messages: Annotated[list, add]
    
    # 不指定 → 替换
    answer: str

# 节点返回
def node(state: State) -> dict:
    return {
        "messages": [new_message],  # 会被追加到现有列表
        "answer": "new answer"       # 会替换旧值
    }
```

### Q17: `app.invoke(None, config)` 报错

**原因**：传 `None` 是为了继续中断后的执行，但需要正确的 config。

**解决**：

```python
config = {"configurable": {"thread_id": "1"}}

# 第一次调用（可能中断）
result = app.invoke({"input": "hello"}, config=config)

# 继续执行
result = app.invoke(None, config=config)  # 必须传同一个 config

# 或更新状态后继续
app.update_state(config, {"field": "new_value"})
result = app.invoke(None, config=config)
```

## 六、性能与成本问题

### Q18: LLM 调用太慢

**优化方案**：

1. 使用 `batch` 代替循环 `invoke`
2. 使用异步 `ainvoke` / `asyncio.gather`
3. 启用缓存
4. 使用更快的模型（gpt-4o-mini 比 gpt-4o 快）
5. 减少输入长度
6. 使用流式输出（提升用户感知速度）

### Q19: API 费用太高

**省钱策略**：

1. 开发时用 `gpt-4o-mini`
2. 启用缓存：`set_llm_cache(InMemoryCache())`
3. 精简 Prompt，减少不必要的 system 消息
4. RAG 中合理设置 `k`（检索数量），不要太大
5. 设置 `max_tokens` 限制输出
6. 减少 Few-Shot 示例数量

## 七、旧版迁移

### Q20: LangChain 版本迁移指南

| 旧版写法（0.1） | 新版写法（0.2+） |
|-----------------|-----------------|
| `from langchain.chat_models import ChatOpenAI` | `from langchain_openai import ChatOpenAI` |
| `from langchain.embeddings import OpenAIEmbeddings` | `from langchain_openai import OpenAIEmbeddings` |
| `from langchain.vectorstores import FAISS` | `from langchain_community.vectorstores import FAISS` |
| `from langchain.text_splitter import ...` | `from langchain_text_splitters import ...` |
| `from langchain.document_loaders import ...` | `from langchain_community.document_loaders import ...` |
| `LLMChain(llm=llm, prompt=prompt)` | `prompt \| llm` (LCEL) |
| `ConversationBufferMemory()` | `RunnableWithMessageHistory()` |
| `from langchain.agents import AgentType` | `create_tool_calling_agent()` |

## 八、调试技巧

### 8.1 查看实际发送的请求

```python
# 打印格式化后的 prompt
prompt = ChatPromptTemplate.from_template("解释{topic}")
formatted = prompt.invoke({"topic": "AI"})

```

### 8.2 逐步调试 Chain

```python

prompt_output = prompt.invoke({"input": "test"})
print("Prompt 输出:", prompt_output)

llm_output = llm.invoke(prompt_output)
print("LLM 输出:", llm_output.content)

parser_output = StrOutputParser().invoke(llm_output)
print("Parser 输出:", parser_output)
```

### 8.3 使用 verbose

```python
# Agent 执行过程
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

from langchain.callbacks import StdOutCallbackHandler
llm = ChatOpenAI(callbacks=[StdOutCallbackHandler()])
```
