## 二、语音转文字 (STT)

### 2.1 使用 OpenAI Whisper

```python
from dotenv import load_dotenv
load_dotenv()

# 方式一：通过API
from langchain_community.document_loaders import OpenAIWhisperAudioLoader

loader = OpenAIWhisperAudioLoader("audio.mp3")
docs = loader.load()
print(docs[0].page_content)

# 方式二：使用openai SDK直接调用
import openai

def transcribe_audio(audio_path: str) -> str:
    """语音转文字"""
    with open(audio_path, "rb") as f:
        result = openai.audio.transcriptions.create(
            model="whisper-1",
            file=f,
            language="zh",  # 指定语言提高准确度
        )
    return result.text

# 方式三：本地Whisper模型（免费，隐私好）
# pip install openai-whisper
import whisper

def transcribe_local(audio_path: str) -> str:
    """本地Whisper转写（免费）"""
    model = whisper.load_model("base")  # tiny/base/small/medium/large
    result = model.transcribe(audio_path, language="zh")
    return result["text"]
```

### 2.2 Whisper 模型大小对比

| 模型 | 大小 | 速度 | 准确度 | 内存需求 |

## 三、文字转语音 (TTS)

```python
import openai

def speak(text: str, voice: str = "alloy", output_path: str = "output.mp3"):
    """文字转语音"""
    response = openai.audio.speech.create(
        model="tts-1",  # tts-1-hd更高质量
        voice=voice,    # alloy/echo/fable/onyx/nova/shimmer
        input=text,
    )
    response.stream_to_file(output_path)
    return output_path

# 使用
speak("你好，欢迎使用AI助手。", voice="nova")
```

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

def voice_conversation(audio_path: str) -> str:
    """完整的语音对话：听→想→说"""

    # Step 1: 语音转文字
    user_text = transcribe_audio(audio_path)
    print(f"👤 用户: {user_text}")

    # Step 2: LLM生成回答
    prompt = ChatPromptTemplate.from_template(
        "你是友好的语音助手。用简洁的口语回答：{input}"
    )
    chain = prompt | llm
    response = chain.invoke({"input": user_text})
    answer = response.content
    print(f"🤖 助手: {answer}")

    # Step 3: 文字转语音
    audio_output = speak(answer)
    print(f"🔊 语音已生成: {audio_output}")

    return audio_output
```

## 五、GPT-4o 音频模式

GPT-4o 支持直接接收音频输入（不需要先转文字）：

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage
import base64

llm = ChatOpenAI(model="gpt-4o-audio-preview")

def chat_with_audio(audio_path: str, question_text: str):
    """直接用音频输入对话"""
    with open(audio_path, "rb") as f:
        audio_b64 = base64.b64encode(f.read()).decode()

    message = HumanMessage(content=[
        {"type": "text", "text": question_text},
        {"type": "input_audio", "input_audio": {"data": audio_b64, "format": "wav"}},
    ])
    response = llm.invoke([message])
    return response.content
```

## 六、场景选型

| 场景 | 推荐方案 | 原因 |
|------|---------|------|
| 语音输入 | Whisper API 或本地 | 中文支持好 |
| 语音输出 | OpenAI TTS | 质量好声音多 |
| 实时对话 | Whisper + LLM + TTS | 通用方案 |
| 低延迟对话 | GPT-4o audio | 端到端少一步 |
| 隐私场景 | 本地Whisper+本地LLM | 数据不外传 |
| 批量转写 | 本地Whisper medium | 免费且质量好 |
