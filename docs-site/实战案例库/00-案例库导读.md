## 案例结构约定

每个案例遵循统一的结构，方便你对照学习：

```
1. 项目背景与目标          ← 为什么做这个、解决什么问题
2. 架构设计（含 Mermaid 图） ← 整体架构和数据流
3. 技术栈与依赖            ← 需要安装什么
4. 完整代码实现             ← 逐文件、逐函数讲解
5. 运行与测试              ← 如何跑起来、如何验证
6. 扩展方向                ← 课后挑战
```
