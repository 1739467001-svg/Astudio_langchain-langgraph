## LLM 调用

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# 单条
response = llm.invoke("你好")
print(response.content)

# 流式
for chunk in llm.stream("讲故事"):
    print(chunk.content, end="")

# 批量
results = llm.batch(["问题1", "问题2"])

# 异步
response = await llm.ainvoke("你好")

# 绑定工具
llm_with_tools = llm.bind_tools([tool1, tool2])

# 结构化输出
structured_llm = llm.with_structured_output(MyModel)
result = structured_llm.invoke("提取信息")
```

## RAG

```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS

# 建库
docs = TextLoader("file.txt").load()
chunks = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50).split_documents(docs)
db = FAISS.from_documents(chunks, OpenAIEmbeddings())
db.save_local("my_index")

# 检索
results = db.similarity_search("query", k=3)
retriever = db.as_retriever(search_kwargs=&#123;"k": 3&#125;)

# RAG链
chain = (
    &#123;"context": retriever | (lambda docs: "\n".join(d.page_content for d in docs)),
     "question": RunnablePassthrough()&#125;
    | prompt | llm | StrOutputParser()
)
```

## LangGraph

```python
from typing import TypedDict, Annotated
from operator import add
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver

# State
class State(TypedDict):
    messages: Annotated[list, add]  # 追加
    result: str                     # 替换

# 节点
def my_node(state: State) -> dict:
    return &#123;"result": "处理完成"&#125;

# 路由
def route(state: State) -> str:
    return "done" if state["result"] else "retry"

# 构图
g = StateGraph(State)
g.add_node("process", my_node)
g.add_edge(START, "process")
g.add_conditional_edges("process", route, &#123;"done": END, "retry": "process"&#125;)
app = g.compile(checkpointer=MemorySaver())

# 运行
result = app.invoke(&#123;"messages": [], "result": ""&#125;)
for event in app.stream(&#123;"messages": [], "result": ""&#125;):
    print(event)

# Human-in-Loop
app = g.compile(checkpointer=MemorySaver(), interrupt_before=["review"])
```

## 快速对照表

| 需求 | 代码 |
|------|------|
| 单次问答 | `llm.invoke("问题")` |
| 流式输出 | `for c in llm.stream("问题"): print(c.content)` |
| 批量处理 | `llm.batch(["q1","q2"])` |
| 模板填充 | `prompt.invoke(&#123;"var": "value"&#125;)` |
| 串联组件 | `prompt \| llm \| parser` |
| 并行执行 | `RunnableParallel(a=..., b=...)` |
| 多轮对话 | `RunnableWithMessageHistory` |
| 创建工具 | `@tool def my_tool(...)` |
| 创建Agent | `create_tool_calling_agent(llm, tools, prompt)` |
| RAG检索 | `db.similarity_search("query", k=3)` |
| 构建图 | `StateGraph(State)` + `add_node` + `add_edge` |
| 条件路由 | `add_conditional_edges(src, func, mapping)` |
| 持久化 | `compile(checkpointer=MemorySaver())` |
| 中断暂停 | `compile(interrupt_before=["node"])` |
| 流式图 | `app.stream(input)` 或 `app.astream_events(input)` |
| 缓存 | `set_llm_cache(InMemoryCache())` |
| 结构化输出 | `llm.with_structured_output(Model)` |
| 绑定工具 | `llm.bind_tools([tool1, tool2])` |

## 常见错误速查

| 错误 | 原因 | 修复 |
|------|------|------|
| `'str' has no 'content'` | 少了 StrOutputParser | 加 `| StrOutputParser()` |
| `TypeError: expected dict` | 管道类型不匹配 | 加 RunnableLambda 转换 |
| `KeyError: 'input'` | 模板变量名不匹配 | 检查占位符 |
| `MaxRetryError` | API限流或网络 | 检查余额/网络 |
| `GraphRecursionError` | Agent无限循环 | 设 `max_iterations` |
| `State字段不更新` | Reducer未设置 | `Annotated[list, add]` |
