# RAG 重排序指南

> 向量检索召回的 Top-20 文档，直接取前 5 个往往不是最优的。重排序（Reranking）用更精确但更慢的模型对候选集重新打分，把最相关的文档排到前面，显著提升 RAG 答案质量。

---

## 1. 为什么需要重排序

### 检索 vs 排序的两阶段架构

```
用户查询
    │
    ▼
┌──────────────┐
│ 第一阶段：召回 │  向量检索（ANN）+ BM25
│ 快但粗        │  从 100 万文档中取 Top-50
│ 目标：高召回率 │  Recall > 95%
└──────┬───────┘
       │ 50 个候选文档
       ▼
┌──────────────┐
│ 第二阶段：重排 │  Cross-encoder / LLM 逐对打分
│ 慢但精        │  从 50 个中精选 Top-5
│ 目标：高精确率 │  Precision > 90%
└──────┬───────┘
       │ 5 个最优文档
       ▼
    LLM 生成答案
```

### 为什么不直接用 Cross-encoder 检索？

| 方面 | 双塔模型（向量检索） | Cross-encoder（重排） |
|------|---------------------|----------------------|
| 速度 | 极快（毫秒级） | 慢（每对 10-50ms） |
| 精度 | 中等 | 高 |
| 可扩展性 | 百万级 | 千级 |
| 原理 | 查询和文档独立编码 | 查询+文档拼接后联合编码 |
| 适用 | 全库召回 | 候选集精排 |

### 性能提升数据

```
基线（无重排）：       Recall@5 = 0.72  →  Answer Accuracy = 0.65
+ Cross-encoder 重排： Recall@5 = 0.89  →  Answer Accuracy = 0.81
+ LLM 重排：           Recall@5 = 0.91  →  Answer Accuracy = 0.84
```

## 2. 三种重排方法

### 方法一：Cross-encoder 重排

最经典的重排方法。将查询和每个候选文档拼接，输入 Cross-encoder 模型，输出相关性分数。

```python
from sentence_transformers import CrossEncoder
from langchain_core.documents import Document

class CrossEncoderReranker:
    """Cross-encoder 重排器"""

    def __init__(self, model_name: str = "cross-encoder/ms-marco-MiniLM-L-6-v2"):
        self.model = CrossEncoder(model_name)
        # 跨语言场景用: "cross-encoder/mmarco-mdistilbert-base-v4"
        # 中文场景用: "BAAI/bge-reranker-base" 或 "BAAI/bge-reranker-large"

    def rerank(
        self,
        query: str,
        documents: list[Document],
        top_k: int = 5,
        batch_size: int = 32,
    ) -> list[Document]:
        """对候选文档重排序

        Args:
            query: 用户查询
            documents: 候选文档列表
            top_k: 返回前 K 个
            batch_size: 批处理大小
        """
        if not documents:
            return []

        # 构造查询-文档对
        pairs = [(query, doc.page_content) for doc in documents]

        # 批量打分
        scores = self.model.predict(pairs, batch_size=batch_size)

        # 按分数排序
        scored_docs = list(zip(documents, scores))
        scored_docs.sort(key=lambda x: x[1], reverse=True)

        # 返回 top_k，附带分数
        reranked = []
        for doc, score in scored_docs[:top_k]:
            doc.metadata["rerank_score"] = float(score)
            reranked.append(doc)

        return reranked
```

**模型选择参考：**

| 模型 | 语言 | 大小 | 速度 | 精度 |
|------|------|------|------|------|
| ms-marco-MiniLM-L-6-v2 | 英文 | 22M | 快 | 中 |
| BAAI/bge-reranker-base | 中英 | 278M | 中 | 高 |
| BAAI/bge-reranker-large | 中英 | 560M | 慢 | 很高 |
| mmarco-mdistilbert | 多语言 | 134M | 中 | 中高 |

### 方法二：LLM 重排

让 LLM 直接对候选文档排序。精度最高但成本也高，适合文档数少（<20）的场景。

```python
from langchain_core.documents import Document
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
import json

class LLMReranker:
    """LLM 重排器：让 LLM 对文档排序"""

    def __init__(self, llm: ChatOpenAI | None = None):
        self.llm = llm or ChatOpenAI(temperature=0, model="gpt-4o-mini")

    def rerank(
        self,
        query: str,
        documents: list[Document],
        top_k: int = 5,
    ) -> list[Document]:
        """LLM 对文档相关性打分"""

        # 构造文档摘要（避免超长）
        doc_summaries = []
        for i, doc in enumerate(documents):
            # 取前 500 字符作为摘要
            summary = doc.page_content[:500].replace("\n", " ")
            doc_summaries.append(f"[&#123;i&#125;] &#123;summary&#125;")

        prompt = ChatPromptTemplate.from_messages([
            ("system", """你是文档相关性评估专家。
根据用户查询，对候选文档按相关性从高到低排序。
只输出 JSON，格式：&#123;&#123;"ranking": [doc_index, ...]&#125;&#125;"""),
            ("user", """查询：&#123;query&#125;

候选文档：
&#123;docs&#125;

请按相关性排序，输出最相关的 &#123;top_k&#125; 个文档索引。"""),
        ])

        chain = prompt | self.llm
        result = chain.invoke(&#123;
            "query": query,
            "docs": "\n\n".join(doc_summaries),
            "top_k": top_k,
        &#125;)

        try:
            data = json.loads(result.content)
            ranking = data["ranking"][:top_k]
            return [documents[i] for i in ranking]
        except (json.JSONDecodeError, KeyError, IndexError):
            # 解析失败，返回原始顺序的前 top_k
            return documents[:top_k]
```

### 方法三：分数融合重排

结合向量相似度和 BM25 分数，用 RRF（Reciprocal Rank Fusion）重排。

```python
class RRFReranker:
    """Reciprocal Rank Fusion 重排器"""

    def __init__(self, k: int = 60):
        """k 是平滑常数，通常 30-100"""
        self.k = k

    def rerank(
        self,
        ranked_lists: list[list[Document]],
        top_k: int = 5,
    ) -> list[Document]:
        """多个排序列表融合

        Args:
            ranked_lists: 多个已排序的文档列表（如向量检索结果 + BM25结果）
            top_k: 返回前 K 个
        """
        scores: dict[str, float] = &#123;&#125;
        doc_map: dict[str, Document] = &#123;&#125;

        for ranked_list in ranked_lists:
            for rank, doc in enumerate(ranked_list):
                doc_id = doc.metadata.get("id", str(hash(doc.page_content)))
                doc_map[doc_id] = doc
                # RRF 公式：score += 1 / (k + rank)
                scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (self.k + rank)

        # 按融合分数排序
        sorted_ids = sorted(scores.items(), key=lambda x: x[1], reverse=True)

        reranked = []
        for doc_id, score in sorted_ids[:top_k]:
            doc = doc_map[doc_id]
            doc.metadata["rrf_score"] = float(score)
            reranked.append(doc)

        return reranked
```

## 3. 生产级重排管线

```python
from dataclasses import dataclass, field
from langchain_core.documents import Document
from langchain_core.retrievers import BaseRetriever

@dataclass
class RerankConfig:
    """重排配置"""
    # 第一阶段：召回
    recall_top_k: int = 50          # 召回数量
    # 第二阶段：重排
    rerank_top_k: int = 5           # 最终返回数量
    # 重排方法
    method: str = "cross_encoder"   # cross_encoder / llm / rrf
    # Cross-encoder
    ce_model: str = "BAAI/bge-reranker-base"
    ce_batch_size: int = 32
    # LLM
    llm_model: str = "gpt-4o-mini"
    llm_max_docs: int = 20          # LLM 重排最多处理文档数
    # RRF
    rrf_k: int = 60
    # 分数过滤
    min_score: float = 0.0          # 最低分数阈值
    # 多样性
    enable_diversity: bool = True
    diversity_lambda: float = 0.5    # 0=纯相关, 1=纯多样


class ProductionRerankRetriever:
    """生产级重排检索器"""

    def __init__(
        self,
        base_retriever: BaseRetriever,
        config: RerankConfig,
    ):
        self.retriever = base_retriever
        self.config = config
        self._reranker = self._init_reranker()

    def _init_reranker(self):
        if self.config.method == "cross_encoder":
            return CrossEncoderReranker(self.config.ce_model)
        elif self.config.method == "llm":
            return LLMReranker()
        elif self.config.method == "rrf":
            return RRFReranker(self.config.rrf_k)
        else:
            raise ValueError(f"未知重排方法: &#123;self.config.method&#125;")

    def get_relevant_documents(self, query: str) -> list[Document]:
        # 第一阶段：粗召回
        candidates = self.retriever.invoke(query)[:self.config.recall_top_k]

        if not candidates:
            return []

        # 第二阶段：重排
        reranked = self._reranker.rerank(
            query=query,
            documents=candidates,
            top_k=self.config.rerank_top_k,
        )

        # 分数过滤
        if self.config.min_score > 0:
            reranked = [
                d for d in reranked
                if d.metadata.get("rerank_score", 0) >= self.config.min_score
            ]

        # 多样性重排
        if self.config.enable_diversity and len(reranked) > 1:
            reranked = self._diversity_rerank(
                query, reranked, self.config.diversity_lambda
            )

        return reranked

    def _diversity_rerank(
        self,
        query: str,
        documents: list[Document],
        lambda_: float,
    ) -> list[Document]:
        """MMR（Maximal Marginal Relevance）多样性重排

        公式：MMR = λ * sim(query, doc) - (1-λ) * max(sim(doc, selected))
        """
        from sentence_transformers import SentenceTransformer
        encoder = SentenceTransformer("all-MiniLM-L6-v2")

        # 编码查询和文档
        query_emb = encoder.encode([query])[0]
        doc_embs = encoder.encode([d.page_content for d in documents])

        selected = []
        remaining = list(range(len(documents)))

        while remaining and len(selected) < self.config.rerank_top_k:
            best_score = -float("inf")
            best_idx = None

            for idx in remaining:
                # 查询相似度
                query_sim = self._cosine(query_emb, doc_embs[idx])

                # 与已选文档的最大相似度
                if selected:
                    max_sim = max(
                        self._cosine(doc_embs[idx], doc_embs[s])
                        for s in selected
                    )
                else:
                    max_sim = 0

                # MMR 分数
                mmr = lambda_ * query_sim - (1 - lambda_) * max_sim
                if mmr > best_score:
                    best_score = mmr
                    best_idx = idx

            selected.append(best_idx)
            remaining.remove(best_idx)

        return [documents[i] for i in selected]

    @staticmethod
    def _cosine(a, b) -> float:
        import numpy as np
        return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))
```

## 4. 重排效果评估

```python
class RerankEvaluator:
    """重排效果评估器"""

    @staticmethod
    def evaluate(
        query: str,
        relevant_doc_ids: set[str],
        before_rerank: list[Document],
        after_rerank: list[Document],
        k: int = 5,
    ) -> dict:
        """对比重排前后效果"""

        def precision_at_k(docs: list[Document], k: int) -> float:
            if not docs:
                return 0.0
            top_k = docs[:k]
            relevant = sum(
                1 for d in top_k
                if d.metadata.get("id") in relevant_doc_ids
            )
            return relevant / k

        def ndcg_at_k(docs: list[Document], relevant_ids: set[str], k: int) -> float:
            """NDCG@K"""
            import math
            dcg = 0
            for i, doc in enumerate(docs[:k]):
                if doc.metadata.get("id") in relevant_ids:
                    dcg += 1 / math.log2(i + 2)  # i+2 因为 log2(1)=0

            # 理想排序
            ideal_hits = min(len(relevant_ids), k)
            idcg = sum(1 / math.log2(i + 2) for i in range(ideal_hits))

            return dcg / idcg if idcg > 0 else 0

        return &#123;
            "precision_before": precision_at_k(before_rerank, k),
            "precision_after": precision_at_k(after_rerank, k),
            "ndcg_before": ndcg_at_k(before_rerank, relevant_doc_ids, k),
            "ndcg_after": ndcg_at_k(after_rerank, relevant_doc_ids, k),
            "improvement_pct": (
                (precision_at_k(after_rerank, k) - precision_at_k(before_rerank, k))
                / max(precision_at_k(before_rerank, k), 0.001)
                * 100
            ),
        &#125;
```

## 5. 配置调优参考

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| recall_top_k | 50-100 | 召回越多越好，但影响延迟 |
| rerank_top_k | 3-5 | 最终给 LLM 的文档数 |
| ce_model | bge-reranker-base | 中英双语推荐 |
| ce_batch_size | 32-64 | GPU 内存决定 |
| min_score | 0.1-0.3 | 过滤明显不相关 |
| diversity_lambda | 0.3-0.5 | 0=纯相关，1=纯多样 |
| LLM max_docs | 15-20 | 超过 20 个成本太高 |

### 延迟预算

```
向量检索 (50 文档):     ~50ms
Cross-encoder 重排:     ~200ms (50对 × 4ms)
LLM 重排 (20 文档):      ~800ms (1次 LLM 调用)
MMR 多样性:              ~50ms
────────────────────────────────
总计：                   ~300ms (Cross-encoder) / ~900ms (LLM)
```
