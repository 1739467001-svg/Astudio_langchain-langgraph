# LLM 应用灾难恢复与备份

> 不是"会不会出事"，而是"什么时候出事"。LLM 应用的灾难恢复有独特挑战：向量索引重建慢、对话历史不可丢、模型 API 可能全面宕机。这份指南覆盖灾备方案、备份策略和恢复流程。

## 三、备份策略

```python
from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum

class BackupType(str, Enum):
    FULL = "full"        # 全量备份
    INCREMENTAL = "incremental"  # 增量备份
    SNAPSHOT = "snapshot"  # 快照

@dataclass
class BackupRecord:
    """备份记录。"""
    backup_id: str
    backup_type: BackupType
    component: str       # vector_db/postgres/config
    size_mb: float
    timestamp: str
    location: str        # S3/本地
    status: str = "completed"  # completed/failed/restoring

class BackupManager:
    """备份管理器。"""

    BACKUP_SCHEDULE = &#123;
        "vector_db": &#123;"type": "full", "frequency": "daily"&#125;,
        "postgres": &#123;"type": "incremental", "frequency": "hourly"&#125;,
        "config": &#123;"type": "full", "frequency": "on_change"&#125;,
    &#125;

    def __init__(self):
        self.backups: list[BackupRecord] = []

    async def backup_vector_db(self) -> BackupRecord:
        """备份向量库。"""
        # 实际：导出向量数据到S3
        return BackupRecord(
            backup_id=f"vec_&#123;datetime.now().strftime('%Y%m%d_%H%M%S')&#125;",
            backup_type=BackupType.FULL,
            component="vector_db",
            size_mb=500.0,
            timestamp=datetime.now().isoformat(),
            location="s3://backups/vector_db/",
        )

    async def backup_database(self, incremental: bool = True) -> BackupRecord:
        """备份数据库。"""
        return BackupRecord(
            backup_id=f"db_&#123;datetime.now().strftime('%Y%m%d_%H%M%S')&#125;",
            backup_type=BackupType.INCREMENTAL if incremental else BackupType.FULL,
            component="postgres",
            size_mb=50.0,
            timestamp=datetime.now().isoformat(),
            location="s3://backups/postgres/",
        )

    def get_latest_backup(self, component: str) -> BackupRecord | None:
        """获取某组件的最新备份。"""
        component_backups = [
            b for b in self.backups if b.component == component and b.status == "completed"
        ]
        return max(component_backups, key=lambda b: b.timestamp) if component_backups else None
```

## 七、最佳实践

| 实践 | 说明 | 优先级 |
|------|------|--------|
| 向量库每日全量备份 | 恢复慢必须提前备份 | ★★★ |
| 数据库每小时增量 | 用户数据不能丢 | ★★★ |
| 多LLM提供商灾备 | OpenAI宕机→Claude | ★★★ |
| 定期灾备演练 | 不演练=没有灾备 | ★★★ |
| 配置用Git管理 | RPO=0 | ★★☆ |
| 备份验证 | 备份不验证=没备份 | ★★☆ |
