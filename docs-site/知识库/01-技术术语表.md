# 技术术语表

> 遇到不认识的技术术语？在这里查找。按字母/拼音排序，持续更新。

---

## A

### Agent（智能代理）
一种能够**自主决策**的 AI 系统。与 Chain（固定流程）不同，Agent 可以根据输入动态决定使用哪些工具、执行什么操作。核心模式是 ReAct：思考→行动→观察→思考。

### AIMessage
对话中 AI（模型）角色的消息。在 LangChain 中用于表示模型的历史回复。

### API（应用程序接口）
程序之间通信的接口。调用 LLM 就是通过 API 发送文本、接收模型生成的回复。

### async / await（异步）
Python 的异步编程语法。在 LLM 应用中用于并发处理多个请求，避免阻塞。

## B

### Batch（批处理）
同时处理多条输入。LangChain 的所有 Runnable 都支持 `batch()` 方法，自动并发。

### Callback（回调）
在执行过程中插入自定义逻辑的机制。常用于日志、监控、计时。

### Chat Model（对话模型）
一种 LLM 接口，接收消息列表（System/Human/AI），返回 AI 消息。现代应用主要使用 Chat Model。

### Chunk（文本块）
文档分割后的小片段。RAG 中把长文档切成多个 chunk 便于向量化检索。

### chunk_size
分割文本时每个块的最大字符数。常见值 300-1000。

### chunk_overlap
相邻文本块之间的重叠字符数。确保上下文不断裂。常见值 50-200。

## C

### Chain（链）
将多个 LangChain 组件串联起来形成的工作流。新版使用 LCEL 的 `|` 管道符。

### ChatPromptTemplate
对话提示词模板，支持 System/Human/AI 多角色消息模板。

### Conditional Edge（条件边）
LangGraph 中根据当前状态选择下一步执行哪个节点的边。实现分支和循环的基础。

### Context Window（上下文窗口）
LLM 一次能处理的最大文本长度（以 token 计）。不同模型从 4K 到 200K+ 不等。

### ConversationBufferMemory（已废弃）
旧版 LangChain 的对话记忆类，保留全部对话历史。新版用 `RunnableWithMessageHistory`。

## D

### Document
LangChain 中表示一段文本的数据结构，包含 `page_content`（文本内容）和 `metadata`（元数据）。

### Document Loader（文档加载器）
用于加载各种格式文件的组件。支持 TXT、PDF、Markdown、网页等。

## E

### Edge（边）
LangGraph 中连接两个节点的路径，定义执行顺序。

### Embedding（嵌入/向量化）
把文本转换为数字向量的过程。语义相近的文本向量也相近，是 RAG 的基础。

### AgentExecutor
执行 Agent 的引擎，管理"思考-行动-观察"循环。

## F

### FAISS
Facebook 开发的向量相似度搜索库。LangChain 中常用作本地向量数据库。

### Few-Shot Prompt（少样本提示）
在提示词中给模型展示几个输入-输出示例，引导模型按期望的模式回答。

### FewShotChatMessagePromptTemplate
LangChain 中创建 Few-Shot 对话提示词的模板类。

## G

### Graph（图）
LangGraph 中的核心数据结构，由节点（Node）和边（Edge）组成的有向图。

## H

### Hallucination（幻觉）
LLM 编造不存在的信息。RAG 的主要目的之一就是减少幻觉。

### Human-in-the-Loop（人机协作）
在 AI 工作流中插入人工审查、确认或修改的环节。

### HumanMessage
对话中用户角色的消息。

## I

### invoke
LangChain Runnable 接口的核心方法，处理单条输入并返回结果。

### Interrupt（中断）
LangGraph 中暂停图执行的功能，常用于 Human-in-the-Loop。

## J

### JSON Output Parser
把 LLM 输出解析为 JSON 对象的解析器。

## L

### LCEL（LangChain Expression Language）
LangChain 的表达式语言，用 `|` 管道符连接组件。统一了 invoke/stream/batch 接口。

### LLM（大语言模型）
基于海量文本训练的 AI 模型，能理解和生成人类语言。如 GPT-4、Claude 等。

### LangSmith
LangChain 官方的可观测性平台，提供追踪、调试、评估功能。

### LangServe（已废弃）
LangChain 旧版的部署工具。已被 LangGraph Platform 替代。

### LLMChain（已废弃）
旧版 LangChain 的链类。新版用 LCEL 管道符替代。

## M

### Max Tokens（最大 Token 数）
LLM 单次输出的最大长度限制。也可在 API 调用中设置。

### Memory（记忆）
让 LLM "记住"对话上下文的机制。新版用 `RunnableWithMessageHistory`。

### MessagesPlaceholder
提示词模板中的占位符，用于动态注入对话历史消息列表。

### Multi-Query Retriever（多查询检索器）
让 LLM 从多个角度重写查询，分别检索后合并结果的检索策略。

## N

### Node（节点）
LangGraph 中的一个处理步骤。是接收 State、返回部分 State 的函数。

## O

### OpenAIEmbeddings
OpenAI 的文本向量化模型，把文本转换为 1536 维向量。

### Output Parser（输出解析器）
把 LLM 的文本回复解析为结构化数据（JSON、列表、对象等）的组件。

## P

### Prompt（提示词）
发送给 LLM 的输入文本。

### PromptTemplate
文本提示词模板，支持变量填充。

### Pydantic
Python 的数据验证库。LangChain 用它定义数据结构和输出格式。

### PydanticOutputParser
把 LLM 输出解析为 Pydantic 对象的解析器，提供类型校验。

### Python-dotenv
从 `.env` 文件读取环境变量的库，常用于安全存放 API Key。

## R

### RAG（检索增强生成）
Retrieval-Augmented Generation。先从知识库检索相关内容，再交给 LLM 生成回答的技术。

### ReAct
Reasoning + Acting 模式。Agent 的基本范式：思考→行动→观察→思考→...→最终答案。

### Reducer（合并器）
LangGraph State 中定义字段更新方式的函数。如 `add` 表示追加，默认是替换。

### Retrieval（检索）
从向量数据库中查找与查询语义最相似的文档片段。

### Runnable
LangChain 中所有可执行组件的统一接口。支持 invoke/stream/batch。

### RunnablePassthrough
LCEL 中的透传组件，输入什么就输出什么。常用于数据组装。

### RunnableLambda
把普通 Python 函数包装成 Runnable 的工具。

### RunnableParallel
并行执行多个 Runnable，合并结果为字典的组件。

### RunnableWithMessageHistory
给 Chain 添加对话历史管理能力的包装器。

## S

### State（状态）
LangGraph 中在所有节点间共享的数据容器。用 TypedDict 或 Pydantic 定义。

### StateGraph
LangGraph 的图构建器，用 State 类型参数化。

### StrOutputParser
最简单的输出解析器，直接提取模型的文本内容（去掉元数据）。

### StructuredTool
LangChain 中用结构化参数（Pydantic 模型）定义的工具。

### Stream（流式输出）
逐字返回 LLM 输出，而非等待全部完成。提升用户体验。

### session_id
对话会话标识符。用于在 Memory 中区分不同用户的对话。

### Subgraph（子图）
LangGraph 中把一部分图封装为独立组件，作为主图的一个节点使用。

### SystemMessage
对话中系统角色的消息，用于设定模型行为和人设。

## T

### Temperature（温度）
控制 LLM 输出随机性的参数。0=确定性输出，1=更有创意。

### Token
LLM 处理文本的基本单位。大约 1 个英文单词 ≈ 1 token，1 个中文字 ≈ 1.5 token。

### Tool（工具）
LLM 可以调用的外部函数。如搜索、计算器、数据库查询等。

### Tool Calling
现代 LLM 原生支持的"函数调用"能力。模型决定调用哪个工具、传什么参数。

### ToolMessage
工具执行后返回的消息类型，包含工具调用的结果。

### TypedDict
Python 的类型工具，用于定义 LangGraph 的 State 类型。

## V

### Vector Store（向量数据库）
存储文本向量并支持相似度搜索的数据库。如 FAISS、Chroma、Pinecone。

### VectorStore Retriever
把向量数据库包装为检索器（Retriever）的接口。

## 常用缩写速查

| 缩写 | 全称 | 含义 |
|------|------|------|
| LLM | Large Language Model | 大语言模型 |
| RAG | Retrieval-Augmented Generation | 检索增强生成 |
| LCEL | LangChain Expression Language | LangChain 表达式语言 |
| API | Application Programming Interface | 应用程序接口 |
| NLP | Natural Language Processing | 自然语言处理 |
| JSON | JavaScript Object Notation | 一种数据格式 |
| ReAct | Reasoning + Acting | 推理+行动模式 |
| HIL | Human-in-the-Loop | 人机协作 |
