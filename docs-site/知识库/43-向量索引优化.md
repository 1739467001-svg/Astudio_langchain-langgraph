# 向量索引优化

> 向量数据库的索引类型直接决定检索速度和准确率。本指南覆盖主流索引算法和调优方法。

---

## 二、主流索引算法

### 2.1 HNSW（推荐）

```mermaid
graph TB
    subgraph HNSW ["HNSW (分层小世界图) "&#125;
        L3["Layer 3: 稀疏<br/>少量节点(快速粗定位)"]
        L2["Layer 2: 中等<br/>更多节点(逐步精化)"]
        L1["Layer 1: 密集<br/>所有节点(精确搜索)"]

        L3 -->|"从顶层开始"| L2
        L2 -->|"下降到下层"| L1
        L1 --> R["结果: 快速定位最近邻"]

        NOTE["✅ 速度快 + 召回率高<br/>❌ 内存占用大<br/>FAISS/Chroma默认使用"]
    end

    style HNSW fill:#E3F2FD
    style R fill:#C8E6C9
```

### 2.2 IVF（倒排索引）

```mermaid
graph TB
    subgraph IVF ["IVF (倒排文件索引) "&#125;
        D["所有文档向量"] --> CLUSTER["聚类为N个簇"]
        CLUSTER --> C1["簇1: 中心向量+成员列表"]
        CLUSTER --> C2["簇2: ..."]
        CLUSTER --> CN["簇N: ..."]

        Q["查询向量"] --> FIND["找到最近的nprobe个簇"]
        FIND --> SEARCH["只在这些簇内搜索"]
        SEARCH --> R["结果: 快速但近似"]

        NOTE["✅ 内存效率高<br/>✅ 可调精度/速度<br/>❌ 需要训练聚类"]
    end

    style IVF fill:#FFF3E0
```

### 2.3 PQ（乘积量化）

```mermaid
graph TB
    subgraph PQ ["PQ (乘积量化) "&#125;
        V["1536维向量"] --> SPLIT["分割为8个子向量"]
        SPLIT --> S1["子向量1: 192维"]
        SPLIT --> S2["子向量2: 192维"]
        SPLIT --> SN["...子向量8"]

        S1 & S2 & SN --> QUANT["每个子向量量化为1字节"]
        QUANT --> R["压缩后: 8字节<br/>(原来1536×4=6144字节)"]

        NOTE["✅ 极大减少内存(75%+)<br/>✅ 适合超大规模<br/>❌ 精度有损失"]
    end

    style PQ fill:#F3E5F5
```

## 四、在 LangChain 中使用索引

### 4.1 FAISS 索引选择

```python
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings
import faiss

embeddings = OpenAIEmbeddings()

# 方式一：默认索引（HNSW）
db = FAISS.from_documents(chunks, embeddings)

# 方式二：自定义索引类型
dimension = 1536  # OpenAI Embedding维度

# 使用IVF索引
quantizer = faiss.IndexFlatL2(dimension)
index = faiss.IndexIVFFlat(quantizer, dimension, nlist=100)  # 100个簇
index.train(vectors)  # 需要训练

# 使用IVF+PQ索引（内存优化）
index = faiss.IndexIVFPQ(quantizer, dimension, 100, 8, 8)  # 8个子向量，每个8位
```

### 4.2 Chroma 索引配置

```python
from langchain_community.vectorstores import Chroma

# Chroma默认使用HNSW
db = Chroma.from_documents(
    chunks,
    embeddings,
    persist_directory="./chroma_db",
    collection_metadata=&#123;"hnsw:space": "cosine"&#125;,  # 可选: cosine/l2/ip
)
```

## 五、调优参数

| 参数 | 说明 | 影响 | 推荐值 |
|------|------|------|--------|
| nlist (IVF) | 簇的数量 | 多=精度高但慢 | sqrt(N) |
| nprobe (IVF) | 搜索时检查的簇数 | 多=召回高但慢 | nlist的10% |
| M (HNSW) | 每个节点的连接数 | 大=精度高但内存大 | 16-48 |
| efConstruction (HNSW) | 构建时搜索宽度 | 大=质量好但慢 | 200-500 |
| efSearch (HNSW) | 查询时搜索宽度 | 大=召回高但慢 | 50-200 |
