# 版本演进与生态

> 了解 LangChain 和 LangGraph 的发展历程、版本变化和周边生态。

---

## 一、LangChain 版本演进

### 1.1 主要版本时间线

| 时间 | 版本 | 关键变化 |
|------|------|----------|
| 2022.10 | v0.0.x | 项目启动，初始发布 |
| 2023.01 | v0.0.150+ | 快速迭代，社区增长 |
| 2023.06 | v0.0.200+ | Agent 和 Tool 体系成熟 |
| 2023.10 | v0.0.330+ | LCEL 引入，Runnable 接口 |
| 2024.01 | v0.1.0 | 第一个稳定版本，API 冻结 |
| 2024.05 | v0.2.0 | 大规模包拆分，废弃旧 API |
| 2024.08 | v0.3.0 | 全面 LCEL 化，移除废弃接口 |

### 1.2 v0.1 到 v0.2/v0.3 的核心变化

**包拆分**：

```
# v0.1：一个大包
pip install langchain

# v0.2+：拆分
pip install langchain              # 核心应用层
pip install langchain-core         # 核心抽象
pip install langchain-community    # 第三方集成
pip install langchain-openai       # OpenAI 专属
pip install langchain-anthropic    # Anthropic 专属
pip install langchain-ollama       # Ollama 专属
```

**API 变化**：

| 变化 | 旧版（v0.1） | 新版（v0.2+） |
|------|-------------|---------------|
| 链构建 | `LLMChain(llm=llm, prompt=prompt)` | `prompt \| llm` (LCEL) |
| 记忆 | `ConversationBufferMemory()` | `RunnableWithMessageHistory()` |
| Agent | `initialize_agent()` | `create_tool_calling_agent()` |
| 导入路径 | `langchain.chat_models` | `langchain_openai` 等专属包 |
| 回调 | `CallbackManager` | `callbacks` 参数 |

### 1.3 废弃 API 列表

以下在 v0.3+ 中已废弃或移除：

| 废弃项 | 替代方案 |
|--------|----------|
| `LLMChain` | `prompt \| llm` (LCEL) |
| `ConversationChain` | `prompt \| llm` + `RunnableWithMessageHistory` |
| `ConversationBufferMemory` | `RunnableWithMessageHistory` |
| `ConversationSummaryMemory` | 自定义摘要逻辑 |
| `initialize_agent()` | `create_tool_calling_agent()` |
| `AgentType.CHAT_ZERO_SHOT_REACT_DESCRIPTION` | `create_tool_calling_agent()` |
| `from langchain.chat_models import ChatOpenAI` | `from langchain_openai import ChatOpenAI` |
| `LLMReplicate` 等旧式集成 | `langchain-community` 包 |
| `LangServe` | `LangGraph Platform` 或 FastAPI |

## 三、生态工具

### 3.1 核心生态

```
LangChain 生态
│
├── LangChain（框架核心）
│   ├── langchain-core        ← 抽象接口
│   ├── langchain             ← 应用层组件
│   ├── langchain-community   ← 第三方集成
│   └── langchain-*           ← 各厂商专属包
│
├── LangGraph（工作流编排）
│   ├── langgraph             ← 核心框架
│   ├── langgraph-checkpoint-* ← 检查点后端
│   └── langgraph-platform    ← 部署平台
│
├── LangSmith（可观测性）
│   ├── 追踪与调试
│   ├── 评估与测试
│   └── 数据集管理
│
├── LangServe（已废弃→LangGraph Platform）
│
└── LangChain Hub（模板库）
    ├── 预构建组件
    └── 社区共享模板
```

### 3.2 LangSmith

LangChain 官方的可观测性平台：

| 功能 | 说明 |
|------|------|
| Tracing | 追踪每次 LLM 调用的完整链路 |
| Evaluation | 对 LLM 输出进行自动化评估 |
| Datasets | 管理测试数据集 |
| A/B Testing | 对比不同 Prompt 或模型的效果 |
| Playground | 在线调试 Prompt |

配置方式：

```env
LANGSMITH_API_KEY=你的密钥
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=my-project
```

### 3.3 LangChain Hub

社区共享的 Prompt 和组件库：

```python
# 拉取社区 Prompt
from langchain import hub
prompt = hub.pull("rlm/rag-prompt")
```

### 3.4 LangGraph Platform

LangGraph 的部署平台（取代 LangServe）：

- 一键部署 LangGraph 工作流
- 自动扩缩容
- 内置持久化和检查点
- API 接口生成

## 四、模型生态

### 4.1 LangChain 支持的模型

| 提供商 | 安装包 | 模型 |
|--------|--------|------|
| OpenAI | `langchain-openai` | GPT-4o, GPT-4o-mini, GPT-4-turbo |
| Anthropic | `langchain-anthropic` | Claude 3.5 Sonnet, Claude 3 Opus |
| Google | `langchain-google-genai` | Gemini 1.5 Pro, Gemini 1.5 Flash |
| Ollama | `langchain-ollama` | Llama 3, Mistral, Qwen2（本地） |
| 阿里云 | `langchain-community` | 通义千问 Qwen |
| 科大讯飞 | `langchain-community` | 星火大模型 |
| 百度 | `langchain-community` | 文心一言 |
| AWS | `langchain-aws` | Bedrock 上的各模型 |
| Mistral | `langchain-mistralai` | Mistral 系列 |
| Cohere | `langchain-cohere` | Command R+ |

### 4.2 模型选择建议

| 场景 | 推荐模型 | 原因 |
|------|----------|------|
| 学习开发 | GPT-4o-mini | 便宜、快、支持 Tool Calling |
| 复杂推理 | GPT-4o / Claude 3.5 Sonnet | 推理能力强 |
| 长文本处理 | Claude 3.5 Sonnet | 上下文窗口大 |
| 中文场景 | 通义千问 / 星火 | 中文理解好，国内可用 |
| 本地/隐私 | Ollama + Llama3 / Qwen2 | 免费、数据不出本地 |
| 成本敏感 | GPT-4o-mini | 最佳性价比 |

## 六、常见替代方案

| 框架 | 特点 | 与 LangChain 对比 |
|------|------|-------------------|
| LlamaIndex | 专注 RAG 和数据连接 | LangChain 更通用；LlamaIndex 在 RAG 方面更专精 |
| Haystack | 企业级 NLP 框架 | 更成熟但更重，LangChain 更灵活 |
| Semantic Kernel | 微软出品，支持 C#/Python | 偏企业 .NET 生态 |
| AutoGen | 微软出品，多 Agent 对话 | 专注多 Agent 协作 |
| CrewAI | 多 Agent 框架 | 更简单但功能少，底层用 LangChain |
| Dify | 可视化 LLM 应用构建 | 低代码，适合非开发者 |

LangChain 的优势在于**生态最完整、社区最大、组件最丰富**。学习 LangChain 后再使用其他框架会非常容易上手。
