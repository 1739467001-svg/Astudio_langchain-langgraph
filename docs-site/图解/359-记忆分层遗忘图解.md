# 记忆分层与遗忘图解

> 工作记忆→短期→长期→情景，巩固+遗忘=记忆高效不膨胀。

---

```mermaid
graph TB
    INPUT["新信息"] --> WORKING["工作记忆<br/>容量小/10min"]
    WORKING --> CONS&#123;"巩固?"&#125;
    CONS -->|重要| SHORT["短期记忆<br/>1h"]
    SHORT --> CONS2&#123;"巩固?"&#125;
    CONS2 -->|重要| LONG["长期记忆<br/>7天"]
    LONG --> EPISODIC["情景记忆<br/>30天"]

    WORKING & SHORT & LONG --> FORGET&#123;"遗忘策略"&#125;
    FORGET -->|TTL| TTL["过期丢弃"]
    FORGET -->|LRU| LRU["最久未用"]
    FORGET -->|LFU| LFU["用得少"]
    FORGET -->|衰减| DECAY["指数衰减"]

    style CONS fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style FORGET fill:#FFE0B2
    style LONG fill:#E3F2FD
```

---

## 遗忘策略

| 策略 | 原理 | 适用 |
|------|------|------|
| TTL | 到期忘 | 临时 |
| LRU | 最久没用 | 缓存 |
| LFU | 用得少 | 热点 |
| 衰减 | 时间指数 | 通用 |
| 混合 | 多维度 | 生产 |
