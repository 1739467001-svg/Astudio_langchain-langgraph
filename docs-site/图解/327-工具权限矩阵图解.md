# 工具权限矩阵图解

> 角色×工具=权限矩阵，Agent组装时动态裁剪工具集，运行时二次校验。

---

```mermaid
graph TB
    USER["用户请求+角色"] --> MATRIX&#123;"权限矩阵<br/>角色×工具"&#125;
    MATRIX -->|允许| GRANT["注入工具集"]
    MATRIX -->|拒绝| DENY["剔除工具"]
    GRANT --> AGENT["Agent执行"]
    AGENT --> CHECK&#123;"运行时校验"&#125;
    CHECK -->|通过| EXEC["执行"]
    CHECK -->|拒绝| BLOCK["阻止+审计"]

    style MATRIX fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style GRANT fill:#C8E6C9
    style BLOCK fill:#FFCDD2,stroke:#C62828
```

---

## 权限模型对比

| 模型 | 粒度 | 复杂度 | 适用 |
|------|------|--------|------|
| 角色级RBAC | 工具 | 低 | 工具<10 |
| 参数级 | 参数值 | 中 | 限参数范围 |
| 属性级ABAC | 上下文 | 高 | 复杂规则 |
| 动态权限 | 运行时 | 高 | 实时风控 |
