# 子图状态映射图解

> 用图解理解 LangGraph 子图与主图之间的状态传递方式。

---

## 一、三种映射模式

```mermaid
graph TB
    subgraph 三种 &#123;"子图状态映射三种模式"&#125;
        M1["模式1: 共享State<br/>主图子图同一State类型<br/>✅ 最简单 ❌ 耦合"]
        M2["模式2: 字段映射<br/>不同State类型<br/>入口/出口手动转换"]
        M3["模式3: 适配器模式<br/>包装器自动转换<br/>✅ 最灵活 ✅ 可复用"]
    end

    style 三种 fill:'#E3F2FD'
```

## 二、共享State

```mermaid
graph LR
    subgraph 共享 &#123;"共享State模式"&#125;
        MAIN["主图State<br/>&#123;topic, research, draft&#125;"] --> SUB["子图直接访问<br/>所有字段"]
        SUB --> MAIN2["子图结果<br/>自动合并回主图"]
    end

    style 共享 fill:'#C8E6C9'
```

## 三、字段映射

```mermaid
graph LR
    subgraph 映射 &#123;"字段映射模式"&#125;
        MS["主图State<br/>&#123;user_question,<br/> research_result&#125;"] --> ENTRY["入口适配器<br/>user_question→query"]
        ENTRY --> SS["子图State<br/>&#123;query, findings&#125;"]
        SS --> EXIT["出口适配器<br/>findings→research_result"]
        EXIT --> MS2["主图State更新"]
    end

    style ENTRY fill:'#FFF9C4'
    style EXIT fill:'#FFF9C4'
```

## 四、适配器模式

```mermaid
graph TB
    subgraph 适配器 &#123;"适配器包装器模式"&#125;
        W["SubGraphWrapper"] --> E["entry_mapper<br/>主图→子图"]
        E --> S["子图执行"]
        S --> X["exit_mapper<br/>子图→主图"]
    end

    style W fill:'#F3E5F5'
```

## 五、模式选择

```mermaid
graph TD
    Q&#123;"子图复用需求?"&#125;
    Q -->|"子图只在一个主图中用"| SHARED["共享State<br/>最简单"]
    Q -->|"子图State不同"| MAPPED["字段映射"]
    Q -->|"子图需要复用到多个主图"| ADAPTER["适配器模式<br/>最灵活"]

    style SHARED fill:'#C8E6C9'
    style ADAPTER fill:'#F3E5F5'
```
