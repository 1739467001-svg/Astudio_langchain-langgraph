# 文档更新策略图解

> 用图解理解增量更新、变更检测和过期检测。

---

## 一、4种更新场景

```mermaid
graph TB
    S1["新增文档"] 
    S2["修改文档"]
    S3["删除文档"]
    S4["批量重建"]

    style S2 fill:#FFF9C4
```

---

## 二、变更检测

```mermaid
graph LR
    DOC["文档"] --> HASH["计算content_hash"]
    HASH --> COMPARE&#123;"与存储的hash比"&#125;
    COMPARE -->|不同| CHANGE["需要更新"]
    COMPARE -->|相同| SKIP["跳过"]

    style COMPARE fill:#FFF9C4
```
