# RAG 离线在线分离图解

> 用图解理解离线建库和在线检索的分离架构。

---

## 一、为什么需要分离

```mermaid
graph TB
    subgraph 混合 &#123;"混合: 互相影响"&#125;
        M1["摄入+查询同进程"] --> M2["❌ 摄入时查询慢"]
    end

    subgraph 分离 &#123;"分离: 互不影响"&#125;
        S1["离线: 批量建库"]
        S2["在线: 低延迟查询"]
    end

    style 混合 fill:#FFCDD2
    style 分离 fill:#C8E6C9
```

---

## 四、部署架构

```mermaid
graph TB
    OFF["离线服务<br/>独立容器"] --> VEC["向量库"]
    ON["在线服务<br/>多副本"] --> VEC
    ON --> CACHE["Redis缓存"]
    OFF -.-> NOTIFY["更新通知"]

    style ON fill:#C8E6C9,stroke:#2E7D32,stroke-width:3px
    style OFF fill:#E3F2FD
```
