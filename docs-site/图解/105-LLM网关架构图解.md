## 二、网关架构

```mermaid
graph TB
    CLIENT["客户端"] --> AUTH["认证"]
    AUTH --> RATE["限流<br/>令牌桶"]
    RATE --> CACHE&#123;"缓存<br/>命中？"&#125;
    CACHE -->|命中| RET["返回"]
    CACHE -->|未命中| ROUTER["路由<br/>选模型"]
    ROUTER --> PROVIDER["模型提供者"]
    PROVIDER --> P1["OpenAI"]
    PROVIDER --> P2["Claude"]
    PROVIDER --> P3["星火"]
    PROVIDER --> FALL["降级链"]
    PROVIDER --> RET

    style ROUTER fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style CACHE fill:#C8E6C9
    style FALL fill:#FFCDD2
```
