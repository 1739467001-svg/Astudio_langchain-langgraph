# 状态快照与时间旅行图解

> 每一步都是完整快照——回到任意步骤、修改状态、重新执行。

---

```mermaid
graph TB
    S0["Step0: 初始"] --> S1["Step1: 搜索"]
    S1 --> S2["Step2: 分析"]
    S2 --> S3["Step3: 报告"]

    S3 -->|"发现问题"| TRAVEL&#123;"时间旅行"&#125;
    TRAVEL --> S1B["回到Step1<br/>修改状态"]
    S1B --> S2B["Step2: 重新执行"]
    S2B --> S3B["Step3: 正确结果"]

    style TRAVEL fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style S3 fill:#FFCDD2,stroke:#C62828
    style S3B fill:#C8E6C9
```

---

## 调试场景

| 场景 | 操作 | 价值 |
|------|------|------|
| 定位错误步骤 | 快照对比 | 找到首次出错 |
| 重跑修正 | 回到+修改 | 不用从头跑 |
| A/B分支 | 同快照不同输入 | 对比路径 |
| 回归测试 | 固定快照重跑 | 验证变更 |
