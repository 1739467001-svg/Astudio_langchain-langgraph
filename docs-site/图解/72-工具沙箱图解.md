# 工具沙箱图解

> 用图解理解 Agent 工具执行的安全隔离架构。

---

## 一、无沙箱 vs 有沙箱

```mermaid
graph TB
    subgraph 无沙箱 &#123;"❌ 无沙箱"&#125;
        A1["Agent代码"] --> S1["直接执行<br/>可访问文件系统<br/>可执行系统命令<br/>❌ 危险"]
    end

    subgraph 有沙箱 &#123;"✅ 有沙箱"&#125;
        B1["Agent代码"] --> F["代码过滤"]
        F --> E["subprocess隔离"]
        E --> W["工作目录限制"]
        W --> D["Docker容器(可选)"]
        D --> R["安全执行 ✅"]
    end

    style 无沙箱 fill:'#FFCDD2'
    style 有沙箱 fill:'#C8E6C9'
```

## 二、四层隔离

```mermaid
graph TB
    subgraph 四层 &#123;"沙箱四层隔离"&#125;
        L1["Layer1: 代码过滤<br/>禁止os/subprocess/eval<br/>正则匹配危险模式"]
        L1 --> L2["Layer2: 执行隔离<br/>subprocess + 超时<br/>限制环境变量"]
        L2 --> L3["Layer3: 文件隔离<br/>临时工作目录<br/>chroot-like"]
        L3 --> L4["Layer4: 容器隔离<br/>Docker容器<br/>无网络+资源限制"]
    end

    style L1 fill:'#C8E6C9'
    style L4 fill:'#F3E5F5'
```

## 三、执行流程

```mermaid
graph TB
    CODE["Agent生成代码"] --> FILTER&#123;"代码过滤"&#125;
    FILTER -->|"含危险代码"| REJECT["❌ 拒绝执行"]
    FILTER -->|"通过"| EXEC["subprocess执行<br/>超时10秒<br/>限制工作目录"]
    EXEC --> CHECK&#123;"成功?"&#125;
    CHECK -->|"是"| OUT["返回输出"]
    CHECK -->|"超时"| TIMEOUT["❌ 超时终止"]
    CHECK -->|"错误"| ERR["返回错误信息<br/>Agent可修复重试"]

    style REJECT fill:'#FFCDD2'
    style OUT fill:'#C8E6C9'
```

## 四、隔离策略选择

```mermaid
graph TD
    Q&#123;"Agent执行什么?"&#125;
    Q -->|"只读数据"| F["Layer1过滤即可"]
    Q -->|"执行代码"| S["Layer1+2"]
    Q -->|"生成文件"| FS["Layer1+2+3"]
    Q -->|"不可信代码"| D["全部四层+Docker"]

    style F fill:'#C8E6C9'
    style D fill:'#F3E5F5'
```
