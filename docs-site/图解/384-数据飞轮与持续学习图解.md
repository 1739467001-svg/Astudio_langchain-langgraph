# 数据飞轮与持续学习图解

> 用户反馈 → 分析根因 → 改进优化 → 更好回答 → 更多用户 → 更多反馈，形成正向飞轮。

---

```mermaid
graph TB
    LAUNCH["系统上线"] --> USE["用户使用"]
    USE --> DATA["产生交互数据<br/>查询/回答/检索"]
    DATA --> FB["收集反馈<br/>赞/踩/修正/投诉"]
    FB --> ANALYZE["分析根因<br/>检索失败? 幻觉? 格式?"]
    ANALYZE --> IMPROVE["改进优化<br/>补知识/调Prompt/加Few-Shot"]
    IMPROVE --> BETTER["更好的回答"]
    BETTER --> MORE["更多用户使用"]
    MORE --> USE

    style FB fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
    style ANALYZE fill:#FFF9C4,stroke:#F9A825,stroke-width:2px
    style IMPROVE fill:#E8F5E9,stroke:#2E7D32,stroke-width:2px
    style BETTER fill:#E8F5E9,stroke:#2E7D32,stroke-width:3px
```

---

## 反馈类型与价值

| 反馈类型 | 价值 | 示例 |
|----------|------|------|
| 用户修正 | 最高 | 用户编辑了回答 |
| 显式反馈 | 高 | 点赞/踩 |
| 隐式反馈 | 中 | 复制/重新生成 |
| 专家标注 | 最高 | 人工审核 |
| AB对比 | 中高 | 灰度测试 |

---

## 运营节奏

| 频率 | 活动 | 输出 |
|------|------|------|
| 实时 | 收集反馈 | 反馈数据 |
| 每日 | 分析隐式信号 | 满意度趋势 |
| 每周 | 分析负面反馈 | 问题报告 |
| 每周 | 执行改进 | 部署更新 |
| 每月 | 评估集更新 | 质量基线 |
