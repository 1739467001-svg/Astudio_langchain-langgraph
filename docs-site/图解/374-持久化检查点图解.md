# LangGraph 持久化检查点与状态恢复图解

> 每个节点执行后自动保存状态快照，崩溃后从最近检查点恢复继续执行。

---

```mermaid
graph TB
    A["节点A"] -->|执行后| CK1&#123;"保存检查点"&#125;
    CK1 --> B["节点B"]
    B -->|执行后| CK2&#123;"保存检查点"&#125;
    CK2 --> C["节点C"]
    C -->|执行后| CK3&#123;"保存检查点"&#125;
    CK1 -.->|"崩溃!"| RECOVER["从检查点恢复"]
    RECOVER -.->|"继续"| B

    style CK1 fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style CK2 fill:#FFF9C4,stroke:#F9A825
    style CK3 fill:#FFF9C4,stroke:#F9A825
    style RECOVER fill:#FFCDD2,stroke:#C62828
    style B fill:#E3F2FD,stroke:#1565C0
```

## 存储后端对比

| 后端 | 持久性 | 性能 | 适用 |
|------|--------|------|------|
| MemorySaver | 重启丢失 | 最快 | 开发调试 |
| SQLite | 本地磁盘 | 快 | 单机生产 |
| Postgres | 数据库 | 中等 | 多实例 |
| Redis | 内存+持久 | 快 | 高并发 |
