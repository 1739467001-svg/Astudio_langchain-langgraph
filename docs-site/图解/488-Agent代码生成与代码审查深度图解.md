# Agent 代码生成与代码审查深度图解

> 需求→代码→审查→修复→测试。本图解可视化代码生成全流程。

---

## 代码生成流程

```mermaid
graph TB
    REQ["需求描述"] --> GEN["代码生成"]
    GEN --> REVIEW["代码审查<br/>6维度评分"]
    REVIEW --> FIX["自动修复"]
    FIX --> TEST["生成测试"]
    TEST --> RUN["运行测试"]
    RUN --> PASS&#123;"通过?"&#125;
    PASS -->|"是"| OUTPUT["✅ 输出"]
    PASS -->|"否"| DEBUG["调试"]

    style GEN fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
    style REVIEW fill:#FFF9C4,stroke:#F9A825,stroke-width=2px
    style OUTPUT fill:#C8E6C9,stroke:#2E7D32,stroke-width=2px
```

---

## 审查维度

| 维度 | 检查内容 | 评分 |
|------|---------|------|
| 代码质量 | 可读性/命名/结构 | 1-5 |
| 错误处理 | 异常处理完善度 | 1-5 |
| 安全性 | 注入风险/敏感信息 | 1-5 |
| 性能 | 算法效率 | 1-5 |
| 可维护性 | 模块化/可扩展 | 1-5 |
| 测试覆盖 | 是否有测试 | 1-5 |
