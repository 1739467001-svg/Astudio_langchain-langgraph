# LLM 应用反馈循环与自动调优图解

> 从反馈中自动学习：收集→分析→优化→验证→部署，形成闭环。

---

```mermaid
graph TB
    COLLECT["收集反馈<br/>显式+隐式"] --> ANALYZE["自动分析<br/>定位问题"]
    ANALYZE --> OPT["生成优化方案<br/>参数/Prompt/策略"]
    OPT --> AB["A/B 验证<br/>新旧对比"]
    AB --> DEPLOY&#123;"更好?"&#125;
    DEPLOY -->|是| LIVE["灰度部署<br/>5%→50%→100%"]
    DEPLOY -->|否| ROLLBACK["回滚"]
    LIVE --> MONITOR["监控效果"]
    MONITOR --> COLLECT

    style COLLECT fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
    style OPT fill:#FFF9C4,stroke:#F9A825,stroke-width:2px
    style AB fill:#E8F5E9,stroke:#2E7D32,stroke-width:2px
    style ROLLBACK fill:#FFCDD2,stroke:#C62828
```

---

## 调优层次

| 层次 | 调什么 | 频率 | 自动化 |
|------|--------|------|--------|
| 参数 | temperature/top_k | 每小时 | 全自动 |
| Prompt | 系统提示/Few-Shot | 每天 | 半自动 |
| 策略 | 检索/分块/路由 | 每周 | 人工审核 |
