# 蓝绿部署图解

> 用图解理解蓝绿部署流程和健康探针机制。

---

## 一、蓝绿部署原理

```mermaid
graph TB
    subgraph 蓝绿 &#123;"蓝绿部署"&#125;
        B["🔵 蓝环境(v1.0)<br/>运行中<br/>100%流量"]
        G["🟢 绿环境(v1.1)<br/>待发布<br/>0%流量"]
        B -.->|"健康检查通过→切流量"| G
        G -.->|"出问题→回滚"| B
    end

    style B fill:'#E3F2FD'
    style G fill:'#C8E6C9'
```

## 二、两种健康探针

```mermaid
graph TB
    subgraph 探针 &#123;"两种健康探针"&#125;
        L["Liveness(存活)<br/>进程是否活着?<br/>'/health/live'<br/>失败→重启容器"]
        R["Readiness(就绪)<br/>依赖是否可用?<br/>'/health/ready'<br/>失败→不接收流量"]
    end

    style L fill:'#FFCDD2'
    style R fill:'#C8E6C9'
```

## 三、部署流程

```mermaid
graph TB
    S1["1.部署绿环境"] --> S2["2.健康检查绿"]
    S2 --> S3&#123;"就绪?"&#125;
    S3 -->|"否"| ABORT["中止"]
    S3 -->|"是"| S4["3.切流量到绿"]
    S4 --> S5["4.监控绿环境"]
    S5 --> S6&#123;"正常?"&#125;
    S6 -->|"否"| ROLL["回滚到蓝"]
    S6 -->|"是"| S7["5.蓝下线<br/>绿→新蓝 ✅"]

    style S3 fill:'#FFF9C4'
    style ROLL fill:'#FFCDD2'
    style S7 fill:'#C8E6C9'
```
