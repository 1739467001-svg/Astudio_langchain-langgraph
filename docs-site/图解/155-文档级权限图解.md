# 文档级权限图解

> 用图解理解权限模型、检索前过滤和检索后验证。

---

## 一、权限控制架构

```mermaid
graph TB
    U["用户(带角色)"] --> PRE["检索前过滤<br/>metadata预筛"]
    PRE --> VEC["向量检索<br/>(允许范围内)"]
    VEC --> POST["检索后验证<br/>二次权限检查"]
    POST --> LLM["LLM生成"]

    style PRE fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style POST fill:#C8E6C9
```

---

## 二、访问级别

```mermaid
graph TB
    PUBLIC["public: 所有人"]
    INTERNAL["internal: 内部员工"]

    CONF["confidential: 机密"]

    style PUBLIC fill:#C8E6C9

```

---

## 三、权限检查

```mermaid
graph TB
    CHECK&#123;"权限检查"&#125; --> EXCLUDE&#123;"在排除列表?"&#125;
    EXCLUDE -->|是| DENY["❌ 拒绝"]
    EXCLUDE -->|否| LEVEL&#123;"访问级别?"&#125;
    LEVEL -->|public| ALLOW["✅ 允许"]
    LEVEL -->|其他| ROLE&#123;"角色/部门匹配?"&#125;
    ROLE -->|是| ALLOW
    ROLE -->|否| DENY

    style DENY fill:#FFCDD2
    style ALLOW fill:#C8E6C9
```
