# 记忆遗忘图解

> 用图解理解 Agent 记忆的遗忘和压缩策略。

---

## 一、记忆膨胀问题

```mermaid
graph TB
    subgraph 膨胀 &#123;"记忆随对话增长"&#125;
        R1["第1轮: 350 tokens"]
        R2["第10轮: 2000 tokens"]

        R1 --> R2 --> R3

    style 膨胀 fill:'#FFCDD2'
```

## 二、三种遗忘策略

```mermaid
graph TB
    subgraph 三种 &#123;"三种遗忘策略"&#125;
        S1["时间衰减<br/>旧消息权重降低<br/>超过半衰期→遗忘"]
        S2["重要性评分<br/>LLM打分<br/>低分→遗忘"]
        S3["摘要压缩<br/>旧消息→摘要<br/>最近消息→完整保留"]
    end

    style S1 fill:'#E3F2FD'
    style S2 fill:'#FFF9C4'
    style S3 fill:'#C8E6C9'
```

## 三、摘要压缩流程

```mermaid
graph LR
    subgraph 压缩前 &#123;"压缩前(50条)"&#125;
        O1["旧消息1-40: 12000 tokens"]
        O2["近期41-50: 2000 tokens"]
    end

    O1 --> SUM["LLM生成摘要<br/>~200 tokens"]
    SUM --> REPLACE["替换为SystemMessage"]
    O2 --> KEEP["完整保留"]
    REPLACE --> AFTER
    KEEP --> AFTER

    subgraph 压缩后 &#123;"压缩后(11条)"&#125;
        AFTER["摘要(200t) + 近期10条(2000t)<br/>= 2200 tokens"]
    end

    style 压缩前 fill:'#FFCDD2'
    style 压缩后 fill:'#C8E6C9'
```

## 四、组合策略

```mermaid
graph TD
    Q&#123;"消息数 > 20?"&#125;
    Q -->|"否"| KEEP["保持不变"]
    Q -->|"是"| S1["Step1: 摘要压缩"]
    S1 --> Q2&#123;"还是 > 20?"&#125;
    Q2 -->|"是"| S2["Step2: 保留最近20条"]
    Q2 -->|"否"| DONE["✅ 完成"]

    style KEEP fill:'#C8E6C9'
    style DONE fill:'#C8E6C9'
```

## 五、选型

| 场景 | 策略 | 原因 |
|------|------|------|
| <10轮 | 不需要 | 不够长 |
| 10-50轮 | 摘要压缩 | 平衡 |
| 50+轮 | 摘要+重要性 | 保留关键 |
| 实时聊天 | 时间衰减 | 自动 |
