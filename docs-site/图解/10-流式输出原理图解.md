## 一、流式输出的底层原理

```mermaid
sequenceDiagram
    participant U as 用户代码
    participant SDK as LangChain SDK
    participant API as OpenAI API
    participant M as LLM模型

    U->>SDK: chain.stream(input)
    SDK->>API: POST /chat/completions &#123;stream: true&#125;
    API->>M: 开始生成

    M-->>API: Token 1 ("你")
    API-->>SDK: data: &#123;"choices": [&#123;"delta": &#123;"content": "你"&#125;&#125;]&#125;
    SDK-->>U: yield "你"

    M-->>API: Token 2 ("好")
    API-->>SDK: data: &#123;"choices": [&#123;"delta": &#123;"content": "好"&#125;&#125;]&#125;
    SDK-->>U: yield "好"

    M-->>API: Token 3 ("！")
    API-->>SDK: data: &#123;"choices": [&#123;"delta": &#123;"content": "！"&#125;&#125;]&#125;
    SDK-->>U: yield "！"

    M-->>API: [DONE]
    API-->>SDK: 流结束
    SDK-->>U: 迭代结束
```

## 四、前端展示：SSE 协议

```mermaid
sequenceDiagram
    participant F as 前端浏览器
    participant S as FastAPI服务端
    participant L as LLM

    F->>S: POST /chat/stream &#123;question: "什么是AI?"&#125;
    
    Note over S: 设置 StreamingResponse<br/>media_type = "text/event-stream"

    S->>L: astream 请求

    loop SSE 事件流
        L-->>S: chunk "A"
        S-->>F: data: A\n\n
        Note over F: EventSource.onmessage<br/>追加 "A" 到页面

        L-->>S: chunk "I"
        S-->>F: data: I\n\n
        Note over F: 追加 "I"
    end

    L-->>S: [DONE]
    S-->>F: [连接关闭]
    Note over F: 流结束
```

### SSE 数据格式

```
data: 第一个chunk\n\n
data: 第二个chunk\n\n
data: 第三个chunk\n\n
```

每个 `data:` 是一条事件，用 `\n\n` 分隔。前端用 EventSource API 接收。

## 五、前端消费流式数据

```javascript
// 前端 JavaScript (EventSource API)
const eventSource = new EventSource('/chat/stream?question=什么是AI?');

let fullAnswer = '';

eventSource.onmessage = function(event) &#123;
    fullAnswer += event.data;
    document.getElementById('answer').innerText = fullAnswer;
&#125;;

eventSource.onerror = function() &#123;
    eventSource.close();
&#125;;
```

### 累积完整结果

```python
# 流式输出时累积完整结果
full_text = ""
for chunk in chain.stream(&#123;"topic": "AI"&#125;):
    print(chunk, end="", flush=True)
    full_text += chunk  # 累积

print(f"\n\n完整结果: &#123;full_text&#125;")
```
