# 多模型路由图解

> 用图解理解按任务复杂度路由到不同模型的策略。

---

## 一、单模型 vs 多模型路由

```mermaid
graph TB
    subgraph 单模型 &#123;"❌ 单模型"&#125;
        U1["所有问题"] --> M1["GPT-4o<br/>$0.016/次"]
    end

    subgraph 多模型 &#123;"✅ 多模型路由"&#125;
        U2["用户问题"] --> RT&#123;"复杂度?"&#125;
        RT -->|"简单"| S1["GPT-4o-mini<br/>$0.001/次 ✅省钱"]
        RT -->|"复杂"| S2["GPT-4o<br/>$0.016/次"]
        RT -->|"代码"| S3["DeepSeek<br/>$0.002/次"]
    end

    style 单模型 fill:'#FFCDD2'
    style 多模型 fill:'#C8E6C9'
```

## 二、三种路由策略

```mermaid
graph TB
    subgraph 三种策略 &#123;"三种路由策略"&#125;
        R1["规则路由<br/>关键词/长度判断<br/>✅最快 ✅免费<br/>⚠️不够灵活"]
        R2["LLM路由<br/>小模型判断复杂度<br/>✅准确 ✅成本低<br/>⚠️多1次调用"]
        R3["级联路由<br/>先用小模型→不够再升级<br/>✅质量有保障<br/>⚠️部分多1次调用"]
    end

    style R1 fill:'#C8E6C9'
    style R2 fill:'#E3F2FD'
    style R3 fill:'#F3E5F5'
```

## 三、级联路由流程

```mermaid
graph TB
    Q["用户问题"] --> SMALL["小模型回答<br/>(GPT-4o-mini)"]
    SMALL --> EVAL&#123;"质量评估"&#125;
    EVAL -->|"合格"| OUT["返回小模型答案 ✅"]
    EVAL -->|"不合格"| LARGE["升级大模型<br/>(GPT-4o)"]
    LARGE --> OUT2["返回大模型答案 ✅"]

    style SMALL fill:'#C8E6C9'
    style LARGE fill:'#FFE0B2'
```
