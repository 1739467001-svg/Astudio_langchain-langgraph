# 优雅扩缩容图解

> 利用率>80%扩容，<30%缩容——扩容快缩容慢，排空后才终止。

---

```mermaid
graph TB
    MON["指标监控"] --> DECIDE&#123;"扩缩容决策"&#125;
    DECIDE -->|利用率高| UP["扩容+N"]
    DECIDE -->|利用率低| DOWN["缩容-N"]
    DECIDE -->|正常| HOLD["保持"]

    UP --> WARM["预热连接池+加载"]
    WARM --> READY["就绪探针通过→接流"]
    DOWN --> DRAIN["连接排空<br/>等在途请求完成"]
    DRAIN --> SHUT["优雅关闭"]

    style DECIDE fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style UP fill:#C8E6C9
    style DOWN fill:#FFE0B2
    style DRAIN fill:#E3F2FD
```

---

## 触发条件

| 指标 | 扩容 | 缩容 | 冷却 |
|------|------|------|------|
| 并发利用率 | >80% | <30% | 60s/120s |
| P95延迟 | >5s | - | 60s |
| 队列长度 | >50 | <5 | 30s |
