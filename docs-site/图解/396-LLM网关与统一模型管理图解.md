## 网关功能

| 功能 | 说明 |
|------|------|
| 统一接口 | 一套SDK调所有模型 |
| 智能路由 | 按请求特征选模型 |
| 降级链 | 主模型不可用自动切换 |
| 限流 | RPM/TPM限制 |
| 缓存 | 相同请求返回缓存 |
| 计费 | 统一成本追踪 |
