## 二、完整语音对话流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant STT as Whisper
    participant L as LLM
    participant TTS as TTS

    U->>STT: 🎤 说话(音频文件)
    Note over STT: 语音转文字
    STT-->>L: "今天天气怎么样？"
    Note over L: LLM处理
    L-->>TTS: "北京今天晴，25°C"
    Note over TTS: 文字转语音
    TTS-->>U: 🔊 播放语音回答
```
