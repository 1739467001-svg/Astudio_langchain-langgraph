# 合规审计图解

> 用图解理解审计日志、合规检查和数据生命周期。

---

## 一、合规审计要求

```mermaid
graph TB
    subgraph 合规 &#123;"5大要求"&#125;
        A1["操作可追溯"]
        A2["内容可审计"]
        A3["数据可追踪"]
        A4["权限可验证"]
        A5["合规可证明"]
    end

    style 合规 fill:#E3F2FD
    style A5 fill:#C8E6C9,stroke:#2E7D32,stroke-width:3px
```

---

## 二、审计日志流

```mermaid
graph LR
    INPUT["用户输入"] --> LOG1["审计记录<br/>输入+用户ID"]
    LOG1 --> LLM["LLM处理"]
    LLM --> LOG2["审计记录<br/>输出+模型+Token"]
    LOG2 --> TOOL["工具调用"]
    TOOL --> LOG3["审计记录<br/>工具+参数+结果"]

    style LOG1 fill:#FFF9C4
    style LOG2 fill:#FFF9C4
    style LOG3 fill:#FFF9C4
```

---

## 三、审计日志脱敏

```mermaid
graph LR
    RAW["原始日志<br/>含手机号/身份证"] --> SANITIZE["脱敏处理<br/>PII→[REDACTED]"]
    SANITIZE --> SAFE["安全日志<br/>可存储可审计"]

    style RAW fill:#FFCDD2
    style SAFE fill:#C8E6C9
```

---

## 四、数据生命周期

```mermaid
graph LR
    CREATE["创建"] --> USE["使用"] --> ARCHIVE["归档"] --> DELETE["删除"]

    style DELETE fill:#FFCDD2
```
