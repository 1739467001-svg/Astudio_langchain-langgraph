# 语义缓存图解

> "什么是AI"和"AI是什么"命中同一缓存——嵌入相似度>0.90即命中。

---

```mermaid
graph TB
    QUERY["用户查询"] --> EMBED["嵌入向量"]
    EMBED --> SEARCH&#123;"缓存中<br/>相似度>0.90?"&#125;
    SEARCH -->|命中| CACHE["返回缓存<br/>跳过LLM"]
    SEARCH -->|未命中| LLM["调用LLM"]
    LLM --> STORE["存入缓存<br/>向量+结果"]
    STORE --> RETURN["返回"]
    CACHE --> RETURN

    style SEARCH fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style CACHE fill:#C8E6C9
    style LLM fill:#E3F2FD
```
