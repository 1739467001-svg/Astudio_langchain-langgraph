# 连接池与资源管理图解

> 复用连接而非每次新建——预热、健康检查、复用率监控三管齐下。

---

```mermaid
graph TB
    REQ["请求"] --> POOL&#123;"连接池<br/>有空闲?"&#125;
    POOL -->|有| REUSE["复用"]
    POOL -->|无| NEW&#123;"未超上限?"&#125;
    NEW -->|是| CREATE["新建"]
    NEW -->|否| WAIT["排队"]
    REUSE & CREATE --> EXEC["执行"]
    EXEC --> RETURN["归还/销毁"]

    style POOL fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style REUSE fill:#C8E6C9
    style WAIT fill:#FFE0B2,stroke:#E65100
```

## 配置调优

| 场景 | min | max | idle超时 | 适用 |
|------|-----|-----|----------|------|
| 低频 | 1 | 5 | 120s | 省资源 |
| 中频 | 3 | 15 | 300s | 通用 |
| 高频 | 5 | 30 | 600s | 低延迟 |
