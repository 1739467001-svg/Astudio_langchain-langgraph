# 子图组合图解

> 大图拆成子图——每个子图独立测试、独立复用，主图通过状态映射组合。

---

```mermaid
graph TB
    subgraph 主图 &#123;"主图编排器"&#125;
        START((开始)) --> ROUTE&#123;"路由"&#125;
        ROUTE -->|检索| SUB1["子图: RAG"]
        ROUTE -->|工具| SUB2["子图: Agent"]
        SUB1 & SUB2 --> MERGE["合并"]
        MERGE --> END((结束))
    end

    subgraph 独立 &#123;"子图可独立测试"&#125;
        SUB1_TEST["RAG子图 ✓"]
        SUB2_TEST["Agent子图 ✓"]
    end

    style ROUTE fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style SUB1 fill:#E3F2FD,stroke:#1565C0
    style SUB2 fill:#F3E5F5,stroke:#6A1B9A
    style MERGE fill:#C8E6C9
```

---

## 组合模式

| 模式 | 结构 | 适用 |
|------|------|------|
| 串行 | A→B→C | 管道 |
| 路由 | 分支→合并 | 分发 |
| 并行扇出 | 分发→聚合 | 多路 |
| 嵌套 | 子图含子图 | 层级 |
