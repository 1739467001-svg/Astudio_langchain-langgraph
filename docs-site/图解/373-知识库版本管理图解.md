# RAG 知识库版本管理与变更追踪图解

> 文档不覆盖，每次变更创建新版本；删除只标记状态；检索可指定版本。

---

```mermaid
graph TB
    DOC["文档变更"] --> CHK&#123;"版本检查"&#125;
    CHK -->|新增| V1["创建 v1<br/>status=active"]
    CHK -->|更新| V2["创建 v2<br/>v1→archived"]
    CHK -->|删除| DEL["标记 deleted<br/>不物理删除"]
    V1 --> LOG["变更日志"]
    V2 --> LOG
    DEL --> LOG
    QUERY["检索查询"] --> SEL&#123;"指定版本?"&#125;
    SEL -->|是| HIST["历史版本"]
    SEL -->|否| LATEST["最新active"]
    LOG --> DIFF["版本对比 diff"]

    style CHK fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style V2 fill:#E3F2FD,stroke:#1565C0
    style DEL fill:#FFCDD2,stroke:#C62828
    style LATEST fill:#C8E6C9
```

---

## 版本状态对比

| 状态 | 含义 | 检索可见 | 可恢复 |
|------|------|----------|--------|
| active | 当前生效 | 是 | — |
| archived | 历史归档 | 仅指定版本 | 可重新激活 |
| deleted | 软删除 | 否 | 可取消删除 |
