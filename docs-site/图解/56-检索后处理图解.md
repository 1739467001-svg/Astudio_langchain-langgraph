# 检索后处理图解

> 用图解理解 RAG 检索后的五步优化管线。

---

## 一、后处理管线

```mermaid
graph LR
    R["检索Top-10"] --> F1["①过滤<br/>去太短/不匹配"]
    F1 --> F2["②去重<br/>去高相似重复"]
    F2 --> F3["③压缩<br/>只保留相关部分"]
    F3 --> F4["④重排序<br/>Cross-Encoder精排"]
    F4 --> F5["⑤截断<br/>按Token限制"]
    F5 --> GEN["送LLM<br/>(Top-3)"]

    style F1 fill:'#E3F2FD'
    style F4 fill:'#FFF9C4'
    style GEN fill:'#C8E6C9'
```

graph TB
