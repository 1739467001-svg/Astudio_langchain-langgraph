# 状态快照图解

> 用图解理解 LangGraph 状态快照的拍照和对比流程。

---

## 一、快照流程

```mermaid
graph LR
    subgraph 快照流程 &#123;"状态快照流程"&#125;
        S1["节点执行前<br/>📸 snap_1"] --> EXEC["执行节点"]
        EXEC --> S2["节点执行后<br/>📸 snap_2"]
        S2 --> NEXT["下一节点前<br/>📸 snap_3"]
    end

    style S1 fill:'#FFF9C4'
    style S2 fill:'#FFF9C4'
```

## 二、快照对比

```mermaid
graph TB
    subgraph 对比 &#123;"snap_1 vs snap_2"&#125;
        C1["snap_1(before_retrieve)<br/>context=''"]
        C2["snap_2(after_retrieve)<br/>context='检索结果...'"]
        C1 --> DIFF["diff:<br/>context: ''→'检索结果...'<br/>✅ 精确定位变化"]
        C2 --> DIFF
    end

    style DIFF fill:'#C8E6C9'
```

## 三、快照 vs Checkpointer

```mermaid
graph TB
    subgraph 区别 &#123;"快照管理器 vs Checkpointer"&#125;
```
