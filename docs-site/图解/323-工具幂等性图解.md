# 工具幂等性图解

> 幂等设计让工具调用可安全重试——请求ID去重 + 指数退避 + 死信兜底。

---

```mermaid
graph TB
    CALL["Agent调用工具"] --> GEN["生成请求ID"]
    GEN --> CHECK&#123;"已执行?"&#125;
    CHECK -->|是| CACHE["返回缓存结果"]
    CHECK -->|否| EXEC["执行工具"]
    EXEC --> TIMEOUT&#123;"超时?"&#125;
    TIMEOUT -->|否| OK["标记完成"]
    TIMEOUT -->|是| RETRY&#123;"重试(指数退避)"&#125;
    RETRY -->|成功| OK
    RETRY -->|失败×3| DLQ["死信队列"]

    style GEN fill:#E3F2FD,stroke:#1565C0
    style CHECK fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style DLQ fill:#FFCDD2,stroke:#C62828
    style OK fill:#C8E6C9
```

---

## 重试策略对比

| 策略 | 公式 | 适用 |
|------|------|------|
| 固定间隔 | delay=1s | 低频 |
| 指数退避 | delay=2^n | 通用 |
| 抖动指数 | delay=2^n×rand | 高并发 |
| 不重试 | 0 | 非幂等 |
