## 五、通信时序

```mermaid
sequenceDiagram
    participant C as 委托Agent
    participant S as 执行Agent

    C->>S: GET /.well-known/agent.json
    S-->>C: Agent Card (能力描述)

    C->>S: POST tasks/send (创建任务)
    S-->>C: Task &#123;id, state: submitted&#125;

    loop SSE流式状态更新
        S-->>C: state=working (进度)
        S-->>C: state=working (进度)
    end

    S-->>C: state=completed
    S-->>C: Artifacts (结果产物)

    Note over C,S: 也可用 tasks/get 轮询状态
    Note over C,S: tasks/cancel 可取消任务
```
