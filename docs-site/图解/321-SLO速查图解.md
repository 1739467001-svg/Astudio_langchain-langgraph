# LLM 应用 SLO 速查图解

> SLI → SLO → SLA + 错误预算 + 告警规则，用一图掌握 LLM 应用可靠性体系。

---

```mermaid
graph TB
    SLI["SLI 指标<br/>延迟/错误率/可用性"] --> SLO["SLO 目标<br/>99%请求<3s"]
    SLO --> BUDGET["错误预算<br/>1%可消耗"]
    BUDGET -->|未耗尽| DEVELOP["可发新功能"]
    BUDGET -->|耗尽| FREEZE["冻结发版<br/>专注稳定性"]

    SLO --> SLA["SLA 合同<br/>99%→赔偿条款"]
    SLO --> ALERT["告警规则<br/>预算消耗速率"]

    style SLO fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
```

## LLM 应用核心 SLO

| SLO 指标 | 目标值 | 告警阈值 | 测量窗口 |
|----------|--------|----------|----------|
| 首Token延迟 | p99 < 2s | p99 > 3s 持续5min | 5min 滚动 |
| 完整响应延迟 | p99 < 8s | p99 > 12s 持续5min | 5min 滚动 |
| 错误率 | < 1% | > 2% 持续3min | 1min 滚动 |
| 可用性 | > 99.5% | < 99% 持续10min | 30天 |
| 幻觉率 | < 5% | > 8% 持续1h | 1h 抽样 |
