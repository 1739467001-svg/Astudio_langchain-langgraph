# 技术选型决策树

> 面对多种选择时，用决策树帮你快速做出合理的技术决策。

---

## 一、Chain vs Agent vs LangGraph

这是最常遇到的选择题：

```mermaid
graph TD
    START["开始选型"] --> Q1

    Q1&#123;"流程是否固定?<br/>每步做什么是否提前知道?"&#125;
    Q1 -->|"是，步骤固定"| Q2&#123;"需要分支或循环吗?"&#125;
    Q1 -->|"否，需要LLM决定"| Q3&#123;"任务复杂度?"&#125;

    Q2 -->|"不需要"| CHAIN["✅ 用 Chain (LCEL)<br/>prompt | llm | parser"]
    Q2 -->|"需要条件分支或循环"| LANGGRAPH["✅ 用 LangGraph"]

    Q3 -->|"简单: 1-2个工具<br/>单轮决策"| AGENT["✅ 用 Agent<br/>create_tool_calling_agent"]
    Q3 -->|"复杂: 多步骤<br/>多Agent协作<br/>需要状态管理"| LANGGRAPH

    Q3 -->|"需要多Agent协作"| MULTI["✅ 用 LangGraph<br/>构建多Agent图"]

    style CHAIN fill:#C8E6C9
    style AGENT fill:#FFE0B2
    style LANGGRAPH fill:#F3E5F5
    style MULTI fill:#E1BEE7
```

### 详细场景对照

```mermaid
graph LR
    subgraph 用Chain ["✅ 用 Chain"]
        C1["翻译任务<br/>(固定: 输入→翻译→输出)"]
        C2["摘要生成<br/>(固定: 输入→摘要→输出)"]
        C3["简单RAG<br/>(固定: 检索→生成)"]
        C4["格式转换<br/>(固定: 输入→转换→输出)"]
    end

    subgraph 用Agent ["✅ 用 Agent"]
        A1["问答助手<br/>(可能需要搜索)"]
        A2["计算器<br/>(可能需要计算工具)"]
        A3["简单助手<br/>(1-3个工具)"]
    end

    subgraph 用LangGraph ["✅ 用 LangGraph"]
        L1["自纠错翻译<br/>(翻译→审查→重试循环)"]
        L2["多Agent系统<br/>(研究→写作→审稿)"]
        L3["条件路由<br/>(按类型分派不同处理)"]
        L4["人工审核流程<br/>(生成→暂停→人工确认→继续)"]
        L5["复杂RAG<br/>(检索→评估→补充检索→生成)"]
    end

    style 用Chain fill:#E3F2FD
    style 用Agent fill:#FFF3E0
    style 用LangGraph fill:#F3E5F5
```
