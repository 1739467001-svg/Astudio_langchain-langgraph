# 成本归因图解

> 用图解理解 Agent 成本的来源分析和归因方法。

---

## 一、成本归因价值

```mermaid
graph TB
    subgraph 无归因 &#123;"❌ 无归因"&#125;
        N1["月$50"] --> N2["不知道哪花的"]
    end

    subgraph 有归因 &#123;"✅ 有归因"&#125;
        S1["月$50"] --> S2["llm: $25(50%)<br/>embedding: $5(10%)<br/>tool: $20(40%)"]
        S2 --> S3["重点优化工具成本"]
    end

    style 无归因 fill:'#FFCDD2'
    style 有归因 fill:'#C8E6C9'
```
