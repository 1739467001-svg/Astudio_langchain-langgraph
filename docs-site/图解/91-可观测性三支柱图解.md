# 可观测性三支柱图解

> 用图解理解 LLM 应用可观测性的三支柱（指标/追踪/日志）、指标分类和分布式追踪原理。

---

## 一、三支柱

```mermaid
graph TB
    ROOT["LLM可观测性三支柱"] --> M["Metrics 指标<br/>聚合数值"]
    ROOT --> T["Traces 追踪<br/>请求级链路"]
    ROOT --> L["Logs 日志<br/>结构化事件"]

    M --> M1["延迟 P50/P95/P99"]
    M --> M2["Token消耗"]
    M --> M3["错误率"]
    M --> M4["缓存命中率"]

    T --> T1["完整调用链"]
    T --> T2["每步输入输出"]
    T --> T3["耗时分解"]

    L --> L1["请求ID关联"]
    L --> L2["结构化JSON"]
    L --> L3["错误堆栈"]

    style ROOT fill:#1565C0,color:#fff
    style M fill:#E3F2FD
    style T fill:#FFF3E0
    style L fill:#C8E6C9
```

## 四、分布式追踪

```mermaid
sequenceDiagram
    participant U as 用户
    participant API as API层
    participant AGENT as Agent编排
    participant LLM as LLM调用
    participant TOOL as 工具调用

    Note over U,TOOL: Trace ID: trace-abc-123

    U->>API: 请求
    Note over API: span: api_handler (2ms)
    API->>AGENT: 处理
    Note over AGENT: span: agent (3500ms)
    AGENT->>LLM: 推理
    Note over LLM: span: llm (3000ms)
    LLM-->>AGENT: 回答
    AGENT->>TOOL: 工具
    Note over TOOL: span: tool (200ms)
    TOOL-->>AGENT: 结果
    AGENT-->>API: 回答
    API-->>U: 响应
```
