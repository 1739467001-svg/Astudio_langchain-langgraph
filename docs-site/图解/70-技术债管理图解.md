# 技术债管理图解

> 用图解理解 LLM 应用特有的技术债类型和偿还策略。

---

## 一、技术债分类

```mermaid
graph TB
    subgraph 六类 &#123;"LLM应用特有技术债六类"&#125;
        D1["📝 Prompt债<br/>硬编码/无版本"]
        D2["🤖 模型债<br/>模型名写死/无降级"]
        D3["📦 组件债<br/>未模块化/难复用"]
        D4["🧪 测试债<br/>无评估集/无回归"]
        D5["📊 监控债<br/>无追踪/无告警"]
        D6["🔒 安全债<br/>无护栏/无脱敏"]
    end

    style D1 fill:'#FFE0B2'
    style D4 fill:'#FFCDD2'
    style D6 fill:'#FFCDD2'
```

## 二、偿还优先级

```mermaid
graph TD
    subgraph 优先级 &#123;"偿还优先级（从紧急到可延后）"&#125;
        P1["🔴 安全债<br/>护栏+脱敏+Key安全<br/>(最紧急)"]
        P1 --> P2["🔴 测试债<br/>评估集+回归测试<br/>(防止变差)"]
        P2 --> P3["🟡 监控债<br/>LangSmith+成本监控<br/>(可观测性)"]
        P3 --> P4["🟡 Prompt债<br/>外部化+版本管理<br/>(可维护性)"]
        P4 --> P5["🟢 组件债<br/>模块化+复用<br/>(可扩展性)"]
    end

    style P1 fill:'#FFCDD2'
    style P5 fill:'#C8E6C9'
```
