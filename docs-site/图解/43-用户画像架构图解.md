# 用户画像架构图解

> 用图解理解用户画像的构建、存储和使用流程。

---

## 一、个性化架构

```mermaid
graph TB
    U["用户输入"] --> PROFILE["加载用户画像"]
    PROFILE --> PROMPT["动态生成<br/>个性化Prompt"]
    PROMPT --> LLM["LLM处理"]
    LLM --> OUT["个性化回答"]
    OUT --> UPDATE["从对话提取<br/>更新画像"]
    UPDATE --> STORE["保存画像"]

    style PROFILE fill:'#E3F2FD'
    style UPDATE fill:'#C8E6C9'
    style STORE fill:'#F3E5F5'
```

## 二、画像数据结构

```mermaid
graph TB
    subgraph 画像 &#123;"用户画像字段"&#125;
        F1["user_id: 用户标识"]
        F2["name: 姓名"]
        F3["language: 偏好语言"]
        F4["tone: 语气偏好<br/>formal/friendly/casual"]
        F5["expertise: 专业水平<br/>beginner/intermediate/expert"]
        F6["interests: 兴趣列表"]
        F7["history_summary: 对话摘要"]
    end

    style 画像 fill:'#E3F2FD'
```

## 三、个性化效果对比

```mermaid
graph TB
```

## 四、画像更新流程

```mermaid
graph LR
    CONV["对话内容"] --> LLM["LLM提取画像信息"]
    LLM --> JSON["JSON结果"]
    JSON --> STORE["更新ProfileStore"]
    STORE --> NEXT["下次对话使用新画像"]

    style LLM fill:'#FFF9C4'
    style STORE fill:'#C8E6C9'
```

## 五、选型建议

| 场景 | 个性化程度 | 方案 |
|------|-----------|------|
| FAQ | 低 | 不需要 |
| 客服 | 中 | 姓名+语气 |
| 教育 | 高 | 水平+历史 |
| 个人助手 | 高 | 完整画像 |
