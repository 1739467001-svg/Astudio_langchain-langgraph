# 流量整形图解

> 用图解理解请求队列和令牌桶如何平滑流量。

---

## 一、流量整形价值

```mermaid
graph TB
    subgraph 无整形 &#123;"❌ 无整形"&#125;
        U1["100并发请求"] --> L1["LLM API"]
        L1 --> R1["❌ 90%限流失败"]
    end

    subgraph 有整形 &#123;"✅ 有整形"&#125;
        U2["100请求"] --> Q["队列<br/>(削峰)"]
        Q --> T["令牌桶<br/>(5 QPS)"]
        T --> L2["LLM API<br/>(平滑)"]
        L2 --> R2["✅ 100%成功<br/>(有排队延迟)"]
    end

    style 无整形 fill:'#FFCDD2'
    style 有整形 fill:'#C8E6C9'
```

## 二、削峰填谷

```mermaid
graph TB
    subgraph 削峰 &#123;"削峰填谷原理"&#125;
        PEAK["请求高峰<br/>(100/秒)"] --> QUEUE["请求队列<br/>排队等待"]
        QUEUE --> SMOOTH["平滑输出<br/>(5/秒)"]
        SMOOTH --> LLM["LLM API<br/>不会限流"]
    end

    style PEAK fill:'#FFCDD2'
    style SMOOTH fill:'#C8E6C9'
```

## 三、令牌桶原理

```mermaid
graph LR
    subgraph 令牌桶 &#123;"令牌桶"&#125;
        T["令牌桶<br/>容量=10<br/>速率=5/秒"] --> CHECK&#123;"有令牌?"&#125;
        CHECK -->|"是"| PASS["放行✅<br/>令牌-1"]
        CHECK -->|"否"| WAIT["等待⏳"]
        WAIT --> T
    end

    style PASS fill:'#C8E6C9'
    style WAIT fill:'#FFF9C4'
```

## 四、完整管线

```mermaid
graph LR
    U["用户请求"] --> Q&#123;"队列满?"&#125;
    Q -->|"是"| REJECT["拒绝: 系统繁忙"]
    Q -->|"否"| QUEUE["排队等待"]
    QUEUE --> SEM["并发许可<br/>(max=5)"]
    SEM --> BUCKET&#123;"令牌桶<br/>有令牌?"&#125;
    BUCKET -->|"是"| LLM["调用LLM"]
    BUCKET -->|"否"| BUCKET

    style REJECT fill:'#FFCDD2'
    style LLM fill:'#C8E6C9'
```
