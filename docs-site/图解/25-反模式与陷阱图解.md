## 四、RAG 反模式

```mermaid
graph TB
    subgraph RAG反模式 &#123;"三种 RAG 反模式"&#125;
        R1["❌ chunk_size=2000<br/>太大→检索不精准→Token浪费"]
        R2["❌ chunk_size=100<br/>太小→上下文不完整→碎片化"]
        R3["❌ 不加元数据<br/>检索结果无法追溯来源"]
        R4["❌ 不评估检索质量<br/>不知道检索到的是否相关"]
        R5["❌ 中文用英文分隔符<br/>分割位置不正确"]
    end

    R1 -.->|"正确"| G1["chunk_size=400-600"]
    R2 -.->|"正确"| G1
    R3 -.->|"正确"| G2["加source/page/chapter"]
    R4 -.->|"正确"| G3["打印检索结果检查"]
    R5 -.->|"正确"| G4["用中文标点分隔符"]

    style R1 fill:#FFCDD2
    style R2 fill:#FFE0B2
    style G1 fill:#C8E6C9
    style G2 fill:#C8E6C9
```
