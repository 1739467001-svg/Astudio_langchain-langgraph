# 特征开关与动态配置图解

> 不重新部署就能开关功能、调整参数——配置中心+本地缓存+变更回调。

---

```mermaid
graph TB
    CENTER["配置中心"] --> CACHE["本地缓存<br/>定期刷新"]
    CACHE --> APP["应用读取"]
    ADMIN["管理界面"] --> CENTER
    CENTER --> NOTIFY["变更通知"]
    NOTIFY --> APP

    subgraph 类型 &#123;"配置类型"&#125;
        FLAG["FLAG: 开/关"]
        VALUE["VALUE: 参数值"]
        JSON["JSON: 复杂配置"]
        SECRET["SECRET: 密钥"]
    end

    style CENTER fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style CACHE fill:#E3F2FD,stroke:#1565C0
    style APP fill:#C8E6C9
```

---

## 配置类型对比

| 类型 | 热更新 | 用途 | 示例 |
|------|--------|------|------|
| FLAG | 是 | 开关 | web_search=true |
| VALUE | 是 | 参数 | temperature=0.3 |
| JSON | 是 | 复杂 | 路由规则 |
| SECRET | 受控 | 密钥 | API Key |
