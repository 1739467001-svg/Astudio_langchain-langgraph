# 多轮规划图解

> 用图解理解动态重新规划。

---

```mermaid
graph TB
    PLAN["初始规划"] --> EXEC["执行"]
    EXEC --> EVAL&#123;"仍有效?"&#125;
    EVAL -->|是| NEXT["下一步"]
    EVAL -->|否| REPLAN["重新规划"]
    REPLAN --> NEXT

    style EVAL fill:#FFF9C4
    style REPLAN fill:#C8E6C9
```
