# 调用链追踪图解

> 一个Agent执行=一棵span树——根span记录总耗时，子span记录每个工具调用，慢节点和失败节点一目了然。

---

```mermaid
graph TB
    ROOT["Root Span<br/>agent.invoke"] --> T1["Span: 工具A"]
    ROOT --> T2["Span: 工具B"]
    T2 --> T2a["Span: 子调用B-1"]
    T2 --> T2b["Span: 子调用B-2"]
    ROOT --> T3["Span: 工具C"]

    T1 --> OK1["✅ 120ms"]
    T2a --> SLOW["⚠ 2.3s 慢"]
    T2b --> OK2["✅ 80ms"]
    T3 --> ERR["❌ 失败"]

    style ROOT fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style SLOW fill:#FFE0B2,stroke:#E65100
    style ERR fill:#FFCDD2,stroke:#C62828
    style OK1 fill:#C8E6C9
```

---

## span 字段速查

| 字段 | 说明 | 示例 |
|------|------|------|
| span_id | 唯一标识 | a1b2c3 |
| parent_id | 父span | f6e5d4 |
| duration_ms | 耗时 | 120.5 |
| status | ok/error/slow | slow |
