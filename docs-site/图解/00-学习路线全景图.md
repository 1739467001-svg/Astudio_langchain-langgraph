## 五、如何使用图解

```mermaid
graph LR
    A[学习新课] --> B&#123;概念不清楚?&#125;
    B -->|是| C[查阅对应图解]
    B -->|否| D[继续学习]
    C --> E[看图理解原理]
    E --> F[回到课程继续]
    F --> D
    D --> G&#123;做练习时卡住?&#125;
    G -->|是| H[查知识库API速查]
    G -->|否| I[完成练习]
    H --> I

    style C fill:#FFF9C4
    style H fill:#FFF9C4
```
