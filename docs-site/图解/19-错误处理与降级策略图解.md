# 错误处理与降级策略图解

> 用图解方式理解 LLM 应用的错误分类、处理流程和降级策略。

---

## 一、错误分类全景

```mermaid
graph TB
    ERROR["🚨 错误发生"]

    ERROR --> CAT1["🔌 基础设施错误<br/>网络/超时/限流"]
    ERROR --> CAT2["📋 格式错误<br/>JSON/类型不匹配"]
    ERROR --> CAT3["🧠 模型行为错误<br/>幻觉/空回复/循环"]
    ERROR --> CAT4["⚙️ 逻辑错误<br/>路由错/State不更新"]

    CAT1 --> H1["处理: 重试+降级+超时"]
    CAT2 --> H2["处理: Parser+安全解析"]
    CAT3 --> H3["处理: Prompt优化+限制"]
    CAT4 --> H4["处理: 调试+条件边检查"]

    style ERROR fill:#FF6F00,color:#fff
    style CAT1 fill:#FFCDD2
    style CAT2 fill:#FFE0B2
    style CAT3 fill:#FFF9C4
    style CAT4 fill:#E3F2FD
    style H1 fill:#C8E6C9
    style H2 fill:#C8E6C9
    style H3 fill:#C8E6C9
    style H4 fill:#C8E6C9
```

## 二、四层防护体系

```mermaid
graph TB
    subgraph 四层防护 ["四层错误防护（由外到内）"]
        L1["Layer 1: 预防<br/>输入验证·参数检查·限额"]
        L2["Layer 2: 重试<br/>指数退避·max_retries"]
        L3["Layer 3: 降级<br/>备用模型·简化逻辑"]
        L4["Layer 4: 兜底<br/>友好消息·记录日志"]
    end

    REQ["请求进入"] --> L1
    L1 -->|"通过"| L2
    L1 -->|"拦截"| REJECT["拒绝请求"]
    L2 -->|"重试成功"| OK["✅ 返回结果"]
    L2 -->|"重试失败"| L3
    L3 -->|"降级成功"| OK
    L3 -->|"降级失败"| L4
    L4 --> FALLBACK["⚠️ 兜底消息"]

    style L1 fill:#C8E6C9
    style L2 fill:#E3F2FD
    style L3 fill:#FFE0B2
    style L4 fill:#FFCDD2
    style OK fill:#C8E6C9
    style FALLBACK fill:#FFE0B2
```

## 七、LangGraph 节点错误处理

```mermaid
graph TB
    START([START]) --> NODE["处理节点<br/>try-catch"]
    NODE --> CHECK&#123;"有错误?"&#125;
    CHECK -->|"无"| NEXT["正常继续"]
    CHECK -->|"有"| HANDLER["错误处理节点"]
    HANDLER --> DECIDE&#123;"可恢复?"&#125;
    DECIDE -->|"是<br/>(如超时)"| RETRY["重试"]
    RETRY --> NODE
    DECIDE -->|"否<br/>(如认证失败)"| FALLBACK["降级回答"]
    FALLBACK --> END([END])
    NEXT --> END

    style NODE fill:#E3F2FD
    style CHECK fill:#FFF9C4
    style HANDLER fill:#FFCDD2
    style RETRY fill:#FFE0B2
    style FALLBACK fill:#FFCDD2
    style NEXT fill:#C8E6C9
```
