# 工具结果缓存图解

> 用图解理解工具结果缓存原理和按工具类型设置TTL。

---

## 一、为什么需要

```mermaid
graph TB
    subgraph 无缓存 &#123;"无缓存"&#125;
        U1["搜索'Python'"] --> T1["执行500ms"]
        U2["搜索'Python'"] --> T2["执行500ms"]
    end

    subgraph 有缓存 &#123;"有缓存"&#125;
        U3["搜索'Python'"] --> T3["执行500ms→缓存"]
        U4["搜索'Python'"] --> T4["✅命中5ms"]
    end

    style 无缓存 fill:#FFCDD2
    style 有缓存 fill:#C8E6C9
```

---

## 二、缓存流程

```mermaid
graph TB
    CALL["工具调用"] --> KEY["生成键<br/>tool+参数hash"]
    KEY --> CHECK&#123;"命中？"&#125;
    CHECK -->|是| RET["返回缓存"]
    CHECK -->|否| EXEC["执行工具"]
    EXEC --> STORE["存缓存"]
    STORE --> RET2["返回"]

    style CHECK fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style RET fill:#C8E6C9
```
