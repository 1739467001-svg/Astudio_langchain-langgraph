# 版本兼容与平滑迁移图解

> 旧会话固定旧版，新会话灰度切新版——State适配器桥接两版数据。

---

```mermaid
graph TB
    USER["请求"] --> ROUTER&#123;"版本路由"&#125;
    ROUTER -->|旧会话| V1["Agent v1"]
    ROUTER -->|新会话| V2["Agent v2"]
    ROUTER -->|灰度| V2
    V1 & V2 --> ADAPTER["状态适配器<br/>v1↔v2"]
    ADAPTER --> SHARED["共享后端"]
    V2 -->|"问题"| ROLLBACK["回滚到v1"]

    style ROUTER fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
```

---

## 迁移策略

| 策略 | 风险 | 适用 |
|------|------|------|
| 灰度迁移 | 低 | 通用 |
| 会话固定 | 极低 | 生产 |
| 状态迁移 | 中 | State变更 |
| 双写对比 | 低 | 高安全 |
| 直接切换 | 高 | 小规模 |
