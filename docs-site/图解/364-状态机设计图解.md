# 状态机设计模式图解

> idle→gather→process→deliver→idle，状态转换表驱动流程。

---

```mermaid
graph TB
    IDLE["空闲"] -->|"开始"| GATHER["信息收集"]
    GATHER -->|"完整"| PROCESS["处理"]
    GATHER -->|"不足"| ASK["追问"]
    ASK --> GATHER
    PROCESS -->|"成功"| DELIVER["交付"]
    PROCESS -->|"失败"| ERROR["错误"]
    ERROR -->|"重试"| PROCESS
    DELIVER -->|"满意"| IDLE

    style GATHER fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style PROCESS fill:#E3F2FD
    style ERROR fill:#FFCDD2
    style DELIVER fill:#C8E6C9
```
