# 知识图谱构建流程图解

> 用图解理解知识图谱三要素、构建流程和 GraphRAG 混合检索。

---

## 一、GraphRAG vs 纯向量RAG

```mermaid
graph LR
    subgraph 向量RAG &#123;"纯向量RAG"&#125;
        VQ["'张三的同事'"] --> V["找相似文档"] --> VR["❌ 没有关系信息"]
    end

    subgraph GraphRAG &#123;"GraphRAG"&#125;
        GQ["'张三的同事'"] --> G["图谱: 张三→colleague→?"] --> GR["✅ 李四、王五"]
    end

    style 向量RAG fill:#FFCDD2
    style GraphRAG fill:#C8E6C9
```

---

## 二、知识图谱三要素

```mermaid
graph TB
    E["Entity 实体<br/>节点"] --> R["Relation 关系<br/>边"]
    R --> A["Attribute 属性<br/>节点特征"]

    ZS["张三<br/>&#123;age:30&#125;"] -->|"works_in"| AI["AI部"]
    LS["李四"] -->|"colleague_of"| ZS

    style E fill:#E3F2FD
    style R fill:#FFF3E0
    style A fill:#C8E6C9
```

---

## 三、构建流程

```mermaid
graph TB
    D["文档"] --> EXT["LLM实体抽取"]
    EXT --> REL["LLM关系抽取"]
    REL --> CLEAN["清洗去重<br/>合并同义实体"]
    CLEAN --> STORE["存入图谱"]
    STORE --> IDX["实体向量化<br/>用于检索"]

    style EXT fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style STORE fill:#C8E6C9
```

---

## 四、混合检索流程

```mermaid
graph TB
    Q["用户查询"] --> ENT["识别查询中的实体"]
    ENT --> GRAPH["图谱查询<br/>实体→关系→邻居"]
    Q --> VEC["向量检索<br/>语义相关文档"]
    GRAPH & VEC --> MERGE["合并结果"]
    MERGE --> LLM["LLM生成回答"]

    style ENT fill:#FFF9C4
    style GRAPH fill:#E3F2FD
    style VEC fill:#FFF3E0
    style MERGE fill:#C8E6C9
```
