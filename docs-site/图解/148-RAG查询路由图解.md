# RAG 查询路由图解

> 用图解理解路由决策、多路检索和RRF融合。

---

## 一、查询路由

```mermaid
graph TB
    Q["查询"] --> CLASSIFY["路由判断"]
    CLASSIFY -->|事实问答| VEC["向量检索"]
    CLASSIFY -->|关系查询| GRAPH["图谱查询"]
    CLASSIFY -->|最新信息| WEB["Web搜索"]
    CLASSIFY -->|复杂分析| MULTI["多路融合"]
    CLASSIFY -->|闲聊| DIRECT["直接回答"]

    style CLASSIFY fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
```

---

## 二、规则路由

```mermaid
graph TB
    Q["查询"] --> R1&#123;"含ID/编号?"&#125;
    R1 -->|是| KW["关键词检索"]
    R1 -->|否| R2&#123;"需最新?"&#125;
    R2 -->|是| WEB["Web搜索"]
    R2 -->|否| R3&#123;"关系查询?"&#125;
    R3 -->|是| GRAPH["图谱查询"]
    R3 -->|否| VEC["向量检索"]

    style R1 fill:#FFF9C4
```

---

## 三、多路融合

```mermaid
graph TB
    Q["查询"] --> V["向量检索"]
    Q --> K["关键词检索"]
    Q --> G["图谱查询"]
    Q --> W["Web搜索"]
    V & K & G & W --> FUSE["RRF融合"]
    FUSE --> FINAL["最终结果"]

    style FUSE fill:#C8E6C9
```
