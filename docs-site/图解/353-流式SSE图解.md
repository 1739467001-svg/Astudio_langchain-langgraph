# 流式输出与SSE图解

> 逐Token推送→SSE格式→前端打字机渲染。首Token延迟从8s降到200ms。

---

```mermaid
graph TB
    AGENT["Agent执行"] --> STREAM["流式输出"]
    STREAM --> TOKEN["Token事件"]
    STREAM --> TOOL["工具事件"]
    STREAM --> ERROR["错误事件"]
    TOKEN & TOOL & ERROR --> SSE["SSE格式<br/>event:data:"]
    SSE --> FRONT["前端打字机"]
    SSE --> HEARTBEAT["心跳保活"]

    style STREAM fill:#FFF9C4,stroke:#F9A825,stroke-width:3px
    style SSE fill:#E3F2FD
    style FRONT fill:#C8E6C9
```

---

## 流式 vs 非流式

| 维度 | 非流式 | 流式 |
|------|--------|------|
| 首Token | 8s | 200ms |
| 用户感知 | 焦虑 | 即时 |
| 超时风险 | 高 | 低 |
| 可中断 | 否 | 是 |
