# 护栏架构图解

> 用图解理解输入输出护栏的双层防护机制。

---

## 一、双层护栏架构

```mermaid
graph LR
    subgraph 双层护栏 &#123;"双层护栏架构"&#125;
        U["用户输入"] --> IG["🛡️ 输入护栏<br/>1. Prompt注入检测<br/>2. PII脱敏<br/>3. 长度/格式验证"]
        IG --> LLM["LLM处理"]
        LLM --> OG["🛡️ 输出护栏<br/>1. 系统提示泄露检测<br/>2. 敏感内容过滤<br/>3. PII二次脱敏<br/>4. 格式验证"]
        OG --> OUT["安全输出 ✅"]
    end

    style IG fill:#FFCDD2
    style OG fill:#FFCDD2
    style OUT fill:#C8E6C9
```

## 二、输入护栏流程

```mermaid
graph TB
    IN["原始输入"] --> V1&#123;"长度检查"&#125;
    V1 -->|"超长"| REJECT1["❌ 拒绝: 输入过长"]
    V1 -->|"正常"| V2&#123;"注入检测"&#125;
    V2 -->|"检测到注入"| REJECT2["❌ 拒绝: 恶意输入"]
    V2 -->|"正常"| V3&#123;"PII脱敏"&#125;
    V3 --> SAFE["✅ 安全输入"]
    V3 --> MASKED["✅ 脱敏输入<br/>'我的手机号是[手机号]'"]

    style REJECT1 fill:#FFCDD2
    style REJECT2 fill:#FFCDD2
    style SAFE fill:#C8E6C9
    style MASKED fill:#C8E6C9
```

## 三、输出护栏流程

```mermaid
graph TB
    OUT["LLM输出"] --> O1&#123;"系统提示泄露?"&#125;
    O1 -->|"是"| BLOCK1["❌ 拦截: 替换为安全消息"]
    O1 -->|"否"| O2&#123;"敏感内容?"&#125;
    O2 -->|"是"| BLOCK2["❌ 拦截: 替换为拒绝消息"]
    O2 -->|"否"| O3&#123;"PII泄露?"&#125;
    O3 -->|"是"| MASK["脱敏处理"]
    O3 -->|"否"| O4&#123;"格式正确?"&#125;
    MASK --> O4
    O4 -->|"是"| SAFE["✅ 安全输出"]
    O4 -->|"否"| REPAIR["尝试修复格式"]
    REPAIR --> SAFE

    style BLOCK1 fill:#FFCDD2
    style BLOCK2 fill:#FFCDD2
    style SAFE fill:#C8E6C9
    style MASK fill:#FFF9C4
```
