## 2 毕业项目：企业内部知识问答 Agent

**项目需求**（虚构）：为一家公司做"制度问答 Agent"——员工问年假、报销、考勤，Agent 给答案、给出处、有礼貌。

**验收标准**：
- 答案必须能溯源到具体制度条款；
- 敏感问题（薪资明细查询他人）必须拒绝；
- 每天 2 万次咨询，成本可控；
- 答错的能快速定位与修正。
